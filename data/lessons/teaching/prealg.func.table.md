# Function Tables

## Inputs and Outputs

A function table lists inputs beside their outputs. Each input has exactly one output, which is what makes the rule a function.

To fill a missing output, substitute the input into the rule and compute. To fill a missing input, solve the rule for the input.

The same rule can be written as an equation, a table or a graph. All three must agree on every pair.

## Finding the Rule

Look for a constant difference or a constant multiplier between consecutive outputs. That pattern suggests the operation in the rule.

A linear rule has equal steps in the output for equal steps in the input. The step size is the coefficient of the input.

Test a candidate rule on at least two rows before trusting it. One row can match by coincidence.

## Using a Table

Tables are useful when the rule is unknown or when only selected values are needed. Interpolation estimates between listed inputs.

Extrapolation continues the pattern beyond the table, but it is only reliable when the rule is known to continue.

Always state the units of the output and check that the table is consistent at both ends.
