# Rationalizing substitutions

## Roots in the integrand



A single square root can be removed by substitution.

Set the root equal to a new variable and solve for x.

The differential changes accordingly.

A single root is removed by naming it as a new variable. Solving for x makes the differential a polynomial in that variable, so the integrand becomes rational.

## The rationalizing substitution



Higher roots require the corresponding power substitution.

The integrand becomes rational in the new variable.

Partial fractions may finish the rational integral.

The substitution is chosen to match the index of the root. After the change the integral contains no radicals and can be finished by standard techniques.

## Back-substituting



Express the antiderivative in the new variable first.

Replace the new variable with the original root.

Check the domain where the root is defined.

The final answer must be written in the original variable. Also check where the root is real, because the substitution is only valid on that domain.
