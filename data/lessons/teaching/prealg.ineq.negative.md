# Inequalities with Negative Coefficients

## Dividing by a Negative

When you divide both sides of an inequality by a negative number, the direction of the inequality reverses. A negative coefficient behaves the same way: isolate x and flip the sign.

Check the reversal with a test value. If -3x < 9, then x > -3, so x = 0 should satisfy the original inequality.

A common error is to reverse only one side. Reverse the comparison symbol once, and never change the numbers themselves.

## Solving Step by Step

Move constants first so the variable term stands alone. Then divide by the coefficient, watching its sign.

For -2x + 5 > 11, subtract 5 to get -2x > 6, then divide by -2 to get x < -3. Both steps are shown so the reversal is visible.

Write the solution as an inequality and test one number on each side of the boundary.

## Integer Solutions

Word problems often ask for the greatest or least integer that satisfies the inequality. Solve the inequality first, then read the boundary.

If x < -3, the greatest integer solution is -4, because -3 itself is excluded. The boundary is not always a solution.

Sketch the solution on a number line and mark whether the endpoint is filled or open before naming an integer.
