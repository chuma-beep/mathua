# Counting Objects

To count a group of objects, point to each object once, and say one number for each object. The last number you say tells you how many objects there are.

**Example 1:** Count the stars:
⭐ ⭐ ⭐ ⭐ ⭐

"One, two, three, four, five" — There are 5 stars.

**Example 2:** Count the circles:
● ● ● ● ● ● ●

"One, two, three, four, five, six, seven" — There are 7 circles.

When counting, it helps to touch each object or move it to one side as you count. This way you count every object exactly once.

**Practice:**
- Count the number of chairs in your room
- Count the number of windows in your house
- Count the number of steps from your front door to the street
