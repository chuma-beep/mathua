# Initial value problems for antiderivatives

This lesson develops initial value problems for antiderivatives through three connected ideas. Work through the sections in order and check each example before moving on.

## From a rate to a family of functions

An antiderivative recovers a function from its derivative, but only up to an additive constant. The constant represents a vertical shift and does not change the derivative.

Write the general antiderivative with a plus C. The family contains every function with the given derivative. A graph of the family is a stack of parallel curves.

The indefinite integral sign denotes the whole family. A definite integral denotes one number. Keeping the two notations separate avoids confusion later.

## Using an initial condition

An initial condition gives the value of the function at one input. Substitute that input and value into the general antiderivative and solve for the constant.

After the constant is known, the solution is unique on the interval where the antiderivative is valid. State that interval when the function has a restricted domain.

Check the answer by differentiating it and by substituting the initial input. Both checks should recover the original data.

## Second-order initial value problems

When the second derivative is given, integrate once to obtain the first derivative and again to obtain the function. Each integration introduces a constant.

Two initial conditions are therefore needed, typically the value of the function and the value of its derivative at the same input. Use the derivative condition first.

This pattern is the simplest differential equation. The same idea extends to higher derivatives, where one condition is needed for each integration.
