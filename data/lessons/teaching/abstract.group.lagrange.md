# Lagrange's Theorem

**Lagrange's theorem:** If $H\le G$ with $G$ finite, then $|H|$ divides $|G|$. The cosets of $H$ partition $G$ into equal-sized blocks, so $|G|=|H|\cdot[G:H]$.

## Divisibility Constraint

### Possible Subgroup Orders
A group of order $12$ can have subgroups of orders $1,2,3,4,6,12$ — each divisor. It cannot have a subgroup of order $5$ ($5\nmid12$).

### Order of Elements
Corollary: the order of any element $g\in G$ divides $|G|$. In a group of order $7$ (prime), every non-identity element has order $7$.

## Example

Can a group of order $24$ have a subgroup of order $8$? Yes — $8\mid24$, so Lagrange allows it (e.g. $D_4\le S_4$). Can it have a subgroup of order $5$? No — $5\nmid24$.
