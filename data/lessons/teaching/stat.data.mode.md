# Mode

The mode is the value that appears most often in a data set. To find it, count how many times each value appears. The value with the highest count is the mode.

For example, in the data set

1, 4, 16, 8, 1, 1, 1, 6

the value 1 appears four times. Every other value appears once. The mode is 1.

## One mode, several modes or no mode

A data set can have one mode, more than one mode or no mode.

If two or more values tie for the highest frequency, each is a mode. A data set with two modes is bimodal; one with more than two is multimodal.

If every value appears the same number of times, there is no mode. For example, 2, 4, 6, 8 has no mode because each value appears once.

## The mode, mean and median

The mode is not the same as the mean or the median. The mean uses every value, the median is the middle value and the mode is the most frequent value. The mode need not sit near the centre of the data.

The mode is useful for categories as well as numbers. If the most common answer to a survey is "blue", then "blue" is the mode, even though it is not a number.

## Finding the mode

Find the mode of 3, 7, 3, 2, 9, 3. The value 3 appears three times, more than any other value, so the mode is 3.
