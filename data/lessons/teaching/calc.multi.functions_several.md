# Functions of Several Variables

A function of several variables assigns one output to a point with several coordinates. Its domain, range and graph are richer than in one variable.

## Inputs and outputs

A function \(f(x,y)\) takes a point \((x,y)\) in the plane and returns a real number. The domain is the set of points where the formula is defined, and the range is the set of output values. Evaluating the function means substituting both coordinates.

For \(f(x,y)=x^2+2y\), the value at \((3,1)\) is \(9+2=11\). The order of the coordinates matters: at \((1,3)\) the value is \(1+6=7\), not 11.

## Domain and range

Square roots require a nonnegative argument, and logarithms require a positive argument. For \(f(x,y)=\sqrt{9-x-y}\), the domain is \(x+y\le 9\). For \(g(x,y)=\ln(9-x-y)\), the boundary is excluded, so the domain is \(x+y<9\).

The range of \(\sqrt{9-x-y}\) is \([0,\infty)\), because the square root is never negative. The range of \(x^2+y^2+1\) is \([1,\infty)\), because the sum of squares is at least zero.

## Graphs and level sets

The graph of \(z=f(x,y)\) is a surface in three dimensions. A level set fixes the output and looks at the corresponding points in the plane. For \(f(x,y)=x^2+y^2\), the level set \(f=9\) is the circle of radius 3.

Level sets compress a three-dimensional graph into a two-dimensional picture. Closely spaced level curves mean the function changes quickly, while widely spaced curves mean it changes slowly.
