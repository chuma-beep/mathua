# Continuity of Functions of Several Variables

## Continuity at a Point

A function of two variables is continuous at a point when its limit there equals its value there. The definition is the same as in one variable, but the limit must agree along every path that approaches the point. Checking only the \(x\)-axis and the \(y\)-axis is not enough, because a function can behave differently along a diagonal or a curve.

Polynomials in \(x\) and \(y\) are continuous everywhere. Sums, products and compositions of continuous functions are continuous wherever they are defined. A rational function is continuous except where its denominator vanishes, and a square root is continuous where its argument is nonnegative.

## Paths and Limits

To show that a limit does not exist, find two paths that give different values. A useful family is the straight lines \(y=mx\), because the limit along such a line often depends on the slope \(m\). If the result changes with \(m\), the original limit cannot exist.

For the function \((x^2-y^2)/(x^2+y^2)\), the limit along \(y=mx\) is \((1-m^2)/(1+m^2)\). Along the \(x\)-axis the value is one, along the line \(y=x\) it is zero, and along \(y=2x\) it is negative three fifths. These different values prove that the function has no limit at the origin.

## Continuous Functions

A function built from continuous pieces is continuous on its domain. The composition of continuous functions is continuous, and a continuous function on a closed bounded region attains a maximum and a minimum. These facts are the multivariable versions of the extreme value theorem.

Continuity is a local property, so a function can be continuous at some points and discontinuous at others. When a formula is undefined at a point but has a limit there, the function can sometimes be extended by defining the missing value to equal the limit. That extension is continuous only when the limit is the same along every path.
