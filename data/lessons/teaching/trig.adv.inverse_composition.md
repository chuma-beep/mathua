# Compositions with Inverse Functions

## Function Followed by Its Inverse

For a value in the domain of the inverse, sin(arcsin x) equals x, and the same pattern holds for cosine and tangent.

The order matters. arcsin(sin x) returns a principal value, which may differ from x when x lies outside the principal range.

Always check that the inner value lies in the domain of the inverse before cancelling the functions.

## Different Functions

A composition such as sin(arccos x) does not cancel. Draw a right triangle with angle whose cosine is x and read the sine from the triangle.

If cos(theta) = x, then the adjacent side is x and the hypotenuse is one, so the opposite side is the square root of one minus x squared.

The sign of the result depends on the quadrant of the inverse value, so the principal range matters.

## Checking a Composition

Evaluate numerically when the exact form is uncertain. A composition that should equal x but does not is a sign of a range error.

Compositions of inverse functions are common in calculus substitutions, where the range choice determines the sign.

Write the domain restriction beside every answer; it is part of the result, not an afterthought.
