# Equations with Rational Exponents

## Rational Powers

An equation with a rational exponent has the unknown inside a power such as x^(m/n). The exponent means the nth root of the mth power, so the equation can be rewritten with a radical. Solving usually means isolating the power and then raising both sides to the reciprocal n/m. For example, x^(2/3) = 4 is solved by raising both sides to the 3/2 power, giving x = 4^(3/2) = 8.

## Solving by Raising

The parity of the denominator controls the domain. An even denominator means an even root, which is only defined for nonnegative radicands when the result is real. An odd denominator allows negative radicands. Raising both sides to an even power can introduce solutions that do not satisfy the original equation, so every candidate must be checked. Raising to an odd power is reversible and does not create that particular problem.

## Checking Solutions

When the exponent is negative, first rewrite the expression as a reciprocal, then solve the positive-exponent equation. When the equation has two terms with rational powers, substituting a new variable for the root can reduce it to a quadratic. The final answer should list only the values that survive the check and should state the solution set explicitly, because an equation with an even root may have no real solution at all.
