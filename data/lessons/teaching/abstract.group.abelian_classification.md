# Classification of finite abelian groups

## Prime Power Pieces

Every finite abelian group decomposes into cyclic groups of prime power order.

The decomposition is unique up to reordering of the factors.

This is the structure theorem for finite abelian groups.

## Counting the Types

The number of abelian groups of order p to the n equals the number of partitions of n.

For a general order, multiply the counts attached to the prime exponents.

The classification problem becomes a small combinatorial calculation.

## Invariant Factors

The invariant factor form orders the cyclic factors so that each order divides the next.

The elementary divisor form keeps the prime powers separate.

Converting between the two forms is a reliable check on the decomposition.

To classify groups of a given order, factor the order and write the exponent of each prime. The number of partitions of each exponent gives the number of types. Multiply those counts to obtain the total for the order.

Two groups of the same order can have different decompositions, so the count is a count of isomorphism types. The partition data records those types without listing every element.
