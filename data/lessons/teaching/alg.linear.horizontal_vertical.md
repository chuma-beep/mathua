# Horizontal and Vertical Lines

## Horizontal Lines

A horizontal line has the same y-value at every point, so its equation is y = k for some constant k. Its slope is zero because the change in y is zero while the change in x is nonzero. Every horizontal line is a function of x, and its graph crosses the y-axis at (0, k). Two horizontal lines are parallel to each other and perpendicular to every vertical line.

## Vertical Lines

A vertical line has the same x-value at every point, so its equation is x = k. Its slope is undefined because the change in x is zero and division by zero is not allowed. A vertical line is not a function of x, since one input has infinitely many outputs. It crosses the x-axis at (k, 0). Every vertical line is parallel to every other vertical line.

## Graphing and Testing

To decide which form applies, compare the coordinates of two points. If the y-values are equal, the line is horizontal and the equation uses y. If the x-values are equal, the line is vertical and the equation uses x. If neither is equal, the line is neither horizontal nor vertical and can be written in slope-intercept or point-slope form. Mixing up the two constant equations is a common error, so checking one point in the equation is a fast way to confirm the choice.
