# Simplifying Algebraic Expressions

## Like Terms

Like terms have the same variable part. Their coefficients can be added or subtracted; the variable part stays unchanged.

3x and 5x combine to 8x. 3x and 5x squared do not combine because the powers differ.

Constants are like terms with no variable, so they combine with each other.

## The Distributive Property

A factor outside parentheses multiplies every term inside. This removes the parentheses before like terms are collected.

2(3x + 4) becomes 6x + 8. The factor must reach both terms, not only the first.

When the factor is negative, watch the signs of every term inside the parentheses.

## A Simplified Expression

An expression is simplified when no parentheses remain and no like terms can be combined. Order of terms does not matter.

Simplification does not change the value of the expression for any input. Test one value before and after to confirm.

Write the result with the variable terms first and the constant last, following the usual convention.
