# Explicit Formulas for Sequences

## Terms from a formula

An explicit formula gives a term directly from its index.
Substitute n into the formula to get the nth term.
No earlier term is needed.

An explicit formula turns the index into a term without any intermediate steps. This makes it possible to compute a distant term such as a_50 directly. It also makes it easy to test whether a proposed value belongs to the sequence.

## Arithmetic and geometric cases

An arithmetic sequence has a constant difference d.
A geometric sequence has a constant ratio r.
Both can be written as explicit formulas in n.

In an arithmetic sequence each step adds the same number, so the formula is linear in n. In a geometric sequence each step multiplies by the same number, so the formula is exponential in n. Recognising which pattern a list follows usually identifies the formula.

## Comparing with recursion

A recursive rule needs one or more starting terms.
An explicit rule jumps straight to any term.
The two descriptions can define the same sequence.

A recursive definition is convenient for describing how a sequence is built, while an explicit formula is convenient for computing one term. Some sequences have both descriptions and some have only a recursion. Converting between the two is a central skill in precalculus.
