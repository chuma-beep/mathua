# Reading Graphs of Relationships

## Axes and Units

The horizontal axis usually holds the input and the vertical axis the output. Read the labels and units before reading any point.

A point is read as an ordered pair. Locate the input on the horizontal axis, move vertically to the graph, then read across.

Graphs can show distance against time, cost against quantity, or any other pair of related quantities.

## Slope and Intercept

The slope describes how fast the output changes per unit of input. The intercept describes the starting value.

A horizontal segment means the output is not changing. A vertical segment is not a function of the horizontal variable.

On a distance-time graph, a steeper line means a faster speed and a flat line means the object is stationary.

## Interpreting Features

Turning points, plateaus and intercepts each have a meaning in context. Name the feature before computing anything.

The x-intercept is where the output is zero; the y-intercept is the output when the input is zero.

Interpretations must stay within the domain of the graph. A model may not apply before the start or after the end of the data.
