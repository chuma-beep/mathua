# Path-Connected Spaces

**Path-connected:** $X$ is path-connected if for any $x,y\in X$ there is a continuous $γ:[0,1]→X$ with $γ(0)=x$, $γ(1)=y$. Every path-connected space is connected; the converse fails.

## Paths vs Connectedness

### Intervals Are Path-Connected
$[0,1]$, $(0,1)$, $\mathbb R^n$ are path-connected via linear paths $γ(t)=(1-t)x+ty$.

### Counterexamples
Topologist's sine curve $\{(x,\sin1/x):x>0\}\cup\{0\}\times[-1,1]$ is connected but not path-connected — no path joins the curve to the limit segment. $\mathbb Q$ is neither.

## Example

Is $\mathbb R^{2}\setminus\{0\}$ path-connected? Yes — go around the missing point via a detour path.
