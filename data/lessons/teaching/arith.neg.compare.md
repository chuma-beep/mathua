# Comparing Negative Numbers

## Order on the Number Line

On a number line, values increase from left to right. A negative number further left is smaller even though its digits look larger. Minus 8 is less than minus 3 because minus 8 lies further left.

The comparison rule reverses the usual digit comparison for negatives. Between minus 8 and minus 3, the one with the larger absolute value is smaller. Between a negative and a positive number, the negative is always smaller.

## Absolute Value and Order

Absolute value measures distance from zero and ignores direction. Minus 8 has absolute value 8 while minus 3 has absolute value 3. The larger absolute value belongs to the smaller negative number.

This relationship explains temperature ordering. Minus 8 degrees is colder than minus 3 degrees, so it is the smaller temperature even though 8 is the larger count of degrees below zero.

## Comparing Several Values

To order a list, separate the negatives from the non-negatives. Sort the negatives by decreasing absolute value, then append the non-negatives in increasing order.

For minus 2, 5, minus 7 and 0, the negatives are minus 2 and minus 7. The order is minus 7, minus 2, 0, 5. A quick sketch on a number line confirms the sequence from left to right.
