# Ratio Tables

## Equivalent Ratios

A ratio table lists pairs that describe the same relationship. Multiplying or dividing both quantities by the same number produces a new column.

If 3 tickets cost 12, then 6 tickets cost 24 and 1 ticket costs 4. Each column keeps the same unit rate.

The table can be extended in either direction, but the multiplier must be applied to both rows.

## Finding a Missing Entry

Use the unit rate, or find the multiplier between a known column and the missing one.

If the input column is multiplied by 5, the output column must also be multiplied by 5.

Cross multiplication is another way to solve the proportion that the table represents.

## Using Ratio Tables

Tables make scaling and comparison visible. They are a bridge between informal reasoning and proportional equations.

A table with a constant difference rather than a constant multiplier describes a linear relationship, not a proportional one.

Check the unit rate in two different columns before concluding that the table is proportional.
