# The Invertible Matrix Theorem

## Equivalent conditions

The invertible matrix theorem collects many statements that are all true together for a square matrix. Invertibility, a nonzero determinant, full rank, a pivot in every row, and a trivial null space are different ways to describe the same property.

## Rank and pivots

Row reduction reveals whether a square matrix is invertible. An n by n matrix needs n pivots, one in every row and column. A missing pivot leaves a free variable, so the homogeneous system has a nontrivial solution and the matrix cannot be inverted.

## Determinants and invertibility

The determinant gives a quick test for small matrices. A nonzero determinant means the matrix is invertible, while a zero determinant means it is singular. The test agrees with the pivot count and with the rank condition, which is the point of the theorem.
