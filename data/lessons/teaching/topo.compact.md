## Definition of compact sets

A set $K$ in a topological (or metric) space is compact if every open cover of $K$ has a finite subcover. Intuitively, compact sets behave like finite sets in many ways. In $\mathbb{R}$ with the usual topology, compactness has a very concrete description.

### Example

The closed interval $[0,1]$ is compact, while the open interval $(0,1)$ is not.

## Heine-Borel theorem

In $\mathbb{R}^n$ with the usual topology, a set is compact if and only if it is closed and bounded. This gives a practical test: check both conditions.

### Example

$[0,1] \cup [2,3]$ is closed and bounded, so it is compact. Its cover by open intervals still has a finite subcover.

## Examples and non-examples

Open sets like $(0,1)$ fail closedness, unbounded sets like $\mathbb{R}$ fail boundedness. Finite unions of compact sets remain compact.
