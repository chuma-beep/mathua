# Cayley's theorem

## Left Multiplication

Let a group act on itself by left multiplication. Each group element sends another element to a product.

The action is faithful because only the identity fixes every element.

This construction turns an abstract group into a set of permutations.

## The Symmetric Group

If the group has n elements, the permutations act on n symbols.

The image is therefore a subgroup of the symmetric group on n symbols.

The degree of the representation is the order of the group.

## What the Theorem Says

Cayley's theorem gives an embedding, not a classification.

It shows that permutation groups are universal examples of groups.

Questions usually ask for the ambient symmetric group or the size of the image.

To answer a question about Cayley's theorem, first identify the group order and then name the symmetric group on that many symbols. The image size equals the group order, so no further calculation is needed for the embedding itself.

Because the action is by left multiplication, every nonidentity element moves the identity to a different point. That single observation proves the representation is faithful and completes the embedding argument.
