# Class Numbers

**Class number $h(D)$:** Size of ideal class group of quadratic order discriminant $D$; $h(D)=1$ ⇔ PID ⇔ UFD. Gauss class number problem solved by Heegner ($h=1$ for $D=-1,-2,-3,-7,-11,-19,-43,-67,-163$).

## Class Number Formula

### Dirichlet Formula
$h(D)=( \sqrt{|D|}/2\pi) L(1,\chi_D)$ for $D<-4$; $L(1,\chi_D)$ Dirichlet L at $1$ encodes class number.

### Stark-Heegner
Largest Heegner $h(-163)=1$; class numbers grow roughly $\sqrt{|D|}$.

## Example

$\mathbb Z[\sqrt{-5}]$ discriminant $-20$, $h=2$ (non-UFD: $6=2·3=(1+\sqrt{-5})(1-\sqrt{-5})$); $h(-163)=1$.
