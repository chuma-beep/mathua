# Exact Sequences

**Exact:** $\operatorname{Im}=\ker$ at each step; short exact $0\to A\to B\to C\to0$ implies $|B|=|A|\cdot|C|$ for finite groups; e.g. $0\to\mathbb Z\stackrel{2}{\to}\mathbb Z\to\mathbb Z/2\mathbb Z\to0$.

## Homological Use

### Five Lemma
Diagram chase: if $4$ of $5$ maps iso, middle iso.

### Split Exact
$0\to A\to B\to C\to0$ split $\Rightarrow B\cong A\oplus C$; tensor right exact only.

## Example

$0\to2\mathbb Z\to\mathbb Z\to\mathbb Z/2\mathbb Z\to0$ exact; $2\mathbb Z\cong\mathbb Z$.
