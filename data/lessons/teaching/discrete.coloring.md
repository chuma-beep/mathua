# Graph Coloring and Chromatic Number

**Chromatic number $\chi(G)$:** Fewest colors so adjacent vertices differ. $\chi(K_n)=n$, bipartite $\chi=2$, odd cycle $C_{2k+1}$ $\chi=3$.

## Coloring Graphs

### Greedy Bound
Greedy coloring uses at most $\Delta+1$ colors ($\Delta$ max degree); Four Color Theorem: planar $\chi\le4$.

### Examples
Petersen graph $\chi=3$; $K_{3,3}$ bipartite $\chi=2$; $C_5$ $\chi=3$.

## Example

Color $K_3$ (triangle): each vertex adjacent to other two, needs $3$ colors, so $\chi=3$.
