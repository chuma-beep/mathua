# Divisibility rules

An integer \(a\) **divides** an integer \(b\) (written \(a \mid b\)) if there exists an integer \(k\) such that \(b = ak\). Divisibility is the fundamental relation in number theory.

### Common divisibility rules

| Divisor | Rule |
|---------|------|
| 2 | Last digit is even (0, 2, 4, 6, 8) |
| 3 | Sum of digits is divisible by 3 |
| 4 | Last two digits form a number divisible by 4 |
| 5 | Last digit is 0 or 5 |
| 6 | Divisible by both 2 and 3 |
| 8 | Last three digits form a number divisible by 8 |
| 9 | Sum of digits is divisible by 9 |
| 10 | Last digit is 0 |

### Key properties

If \(a \mid b\) and \(a \mid c\), then \(a \mid (b + c)\) and \(a \mid (b - c)\).

If \(a \mid b\) and \(b \mid c\), then \(a \mid c\) (transitivity).

If \(a \mid b\) and \(a \mid c\), then \(a \mid (mb + nc)\) for any integers \(m, n\) (linear combination).
