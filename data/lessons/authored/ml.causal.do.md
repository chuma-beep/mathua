# The do-calculus

The do-calculus turns an intervention into an ordinary conditional probability when the graph allows it. It has three rules, each licensed by a graphical condition.

## The intervention

Setting a variable to a value removes the edges into it. The resulting graph describes the post-intervention distribution.

## The rules

Three rules insert or delete observations and interventions. Each rule requires a d-separation statement in a mutilated graph.

## Identifiability

A causal effect is identifiable when the rules reduce it to observed quantities. If no sequence applies, the effect is not identified by the graph.

To check your understanding, cut the incoming edges, apply rule one and reduce to observables.

The do-calculus is algebra for interventions, with graph conditions as side premises.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller numbers and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
