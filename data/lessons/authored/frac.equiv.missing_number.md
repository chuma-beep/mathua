# Finding a missing numerator or denominator

A missing part of an equivalent pair is found by matching the scale factor between the known parts. The same factor must apply to the numerator and the denominator.

## The rule

In \(\frac{a}{b} = \frac{x}{d}\), compare \(b\) with \(d\). If \(d = kb\), then \(x = ka\). When the numerator is known instead, solve \(a = kx\) for the multiplier. Cross multiplication gives the same answer: \(ad = bx\), so \(x = \frac{ad}{b}\), which requires \(b\) nonzero. For \(\frac{2}{3} = \frac{x}{9}\) the multiplier is 3 and \(x = 6\).

## A worked example

Complete \(\frac{3}{5} = \frac{x}{20}\). The denominator grows from 5 to 20 by a factor of 4, so the numerator is \(3 \times 4 = 12\), giving \(\frac{12}{20}\). Now complete \(\frac{7}{8} = \frac{21}{x}\). The numerator grows from 7 to 21 by a factor of 3, so the denominator is \(8 \times 3 = 24\). A third case is \(\frac{9}{12} = \frac{x}{4}\), where the denominator shrinks by a factor of 3 and the numerator becomes 3.

## Checking the result

Cross multiply the completed equality. For the first case, \(3 \times 20 = 60\) and \(5 \times 12 = 60\), so the parts agree. For the second, \(7 \times 24 = 168\) and \(8 \times 21 = 168\). Reducing each completed fraction returns the original, which is the same check seen from the other side.

The missing number is the one that keeps both cross products equal.
