# Block matrices

A block matrix treats smaller matrices as entries. Block multiplication and block determinants follow the usual rules when the block sizes match.

## Block-diagonal determinant

A block-diagonal matrix has square blocks on the diagonal and zeros elsewhere. Its determinant is the product of the block determinants. This rule turns a large determinant into smaller ones.

## Trace

The trace of a block matrix is the sum of the traces of its diagonal blocks. Off-diagonal blocks do not contribute. The rule holds for any square block partition.

## Block multiplication

Multiply block matrices as if the blocks were scalars, provided the inner dimensions match. The (1,1) block of M squared is A squared when M is block diagonal. The off-diagonal zero blocks stay zero.
