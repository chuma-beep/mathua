# Operating on piecewise functions

Piecewise functions are combined branch by branch. The sum or product is defined only where both functions are defined.

## Combining branches

Evaluate each function on the branch that contains the input. Add or multiply the two values. The result is the value of the combined function at that input.

## Common domain

The domain of a sum or product is the intersection of the two domains. A point outside either domain is outside the combined domain. The branch formulas do not repair a missing input.

## Reading the result

A piecewise result may have a jump at a branch boundary. The combined function inherits both jumps. Check the boundary points separately when the question asks for continuity.
