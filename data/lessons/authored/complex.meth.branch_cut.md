# Branch cuts

A multivalued function needs a cut joining its branch points before a single-valued branch can be chosen.

## Branch points

A branch point is a point around which the function changes value after one loop, as zero and infinity do for the logarithm.

## Cuts

A cut is a curve joining branch points that the domain avoids, so the remaining region is simply connected.

## Principal branch

On the cut plane the principal argument lies in a fixed interval, which fixes the logarithm and every power.

To check your understanding, locate a branch point, join the branch points and fix the argument range.

A branch cut turns a multivalued expression into a function.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller values and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
