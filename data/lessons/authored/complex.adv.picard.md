# Picard's theorem

Picard's great theorem says an essential singularity omits at most one value in every neighbourhood. Picard's little theorem says a nonconstant entire function omits at most one value.

## Identify the exceptional value

The exponential function omits zero. A nonconstant entire function can omit at most one value. The omitted value is called the exceptional value.

## Count omitted values

At most one value can be omitted near an essential singularity. A function that omits two values cannot have an essential singularity there. The count is the key hypothesis.

## Apply Picard's theorem

Picard strengthens Casorati-Weierstrass from density to all but one value. It is used to classify entire functions and singularities. The theorem is existence-heavy and rarely gives a numerical value directly.
