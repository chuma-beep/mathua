# The Dirichlet problem

The Dirichlet problem asks for a harmonic function with prescribed boundary values. On a disk it has a unique solution for continuous boundary data.

## Boundary data

The boundary values are given on the circle. The solution is harmonic inside and continuous up to the boundary. Constant boundary data produces the same constant inside.

## An interior point

The value at an interior point is determined by the boundary data. For constant data it is that constant. For nonconstant data it is a weighted average of the boundary values.

## Uniqueness

If two harmonic functions have the same boundary data, their difference is harmonic and zero on the boundary. The maximum principle forces the difference to be zero. The solution is unique.
