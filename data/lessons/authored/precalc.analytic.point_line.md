# Distance from a point to a line

The distance from a point to a line is the length of the perpendicular segment from the point to the line. A formula computes it directly from the line equation.

## The formula

For the line with equation a x + b y + c = 0, the distance from a point is the absolute value of the left side at that point divided by the square root of a squared plus b squared.

## Why the denominator

The denominator normalises the coefficient vector, so the formula measures length rather than an arbitrary scaled quantity.

## Perpendicular construction

The same distance can be found by writing the perpendicular through the point, intersecting it with the line and applying the distance formula.

Take the absolute value last, because the signed value only says which side of the line the point lies on.
