# Negative mixed numbers as improper fractions

A negative mixed number converts to an improper fraction by converting the positive part and then applying the sign to the whole result. The fraction part is not subtracted.

## The method

For a positive whole number \(w\), a fraction \(\frac{a}{b}\) and a negative sign, \(-w\frac{a}{b} = -\frac{wb + a}{b}\). The sign applies to the entire value, which sits left of zero at distance \(w + \frac{a}{b}\). Writing \(-\frac{wb - a}{b}\) is wrong because it shortens the distance. For \(w = 1\) and \(\frac{1}{2}\) the result is \(-\frac{3}{2}\). The sign is applied once, after the conversion, so the magnitude follows the positive case.

## A worked example

Convert \(-2\frac{3}{4}\). The positive mixed number is \(\frac{11}{4}\), so the negative value is \(-\frac{11}{4}\). The common error gives \(-\frac{5}{4}\), which equals negative one and a quarter, while the correct value is negative two and three quarters. A second case is \(-1\frac{1}{2} = -\frac{3}{2}\).

## Checking the result

Write the improper fraction as a decimal: \(-\frac{11}{4} = -2.75\), which matches \(-2\frac{3}{4}\) on the number line. Dividing 11 by 4 gives 2.75, so the magnitude is right and the sign is attached once. The second case checks as \(-\frac{3}{2} = -1.5\).

The sign belongs to the whole mixed number and the fraction part never flips it.
