# Evaluating expressions at negative values

## Substituting a Negative Value

To evaluate an expression, replace each variable with its value and follow the order of operations. Put the substituted number in brackets so the sign stays attached. For \\(3x + 2\\) at \\(x = -4\\), write \\(3(-4) + 2\\), which is \\(-12 + 2 = -10\\).

Without brackets, a hasty reader sees 3 minus 4 and gets a different answer. The brackets are not decoration; they record that the negative number is multiplied by three.

## Squares of Negative Numbers

A square applies to whatever is inside the brackets. So \\((-5)^2 = 25\\), because a negative times a negative is positive. Written as \\(-5^2\\), the square applies only to 5, giving -25.

Evaluate \\(x^2 - 2x\\) at \\(x = -3\\). The first term is \\((-3)^2 = 9\\). The second is \\(-2(-3) = 6\\), so the value is \\(9 + 6 = 15\\). Watch the second term, because subtracting a negative product adds.

## Subtracting a Product

A minus sign before a product applies to the whole product. Evaluate \\(10 - 4x\\) at \\(x = -2\\). The product is \\(4(-2) = -8\\), so the expression becomes \\(10 - (-8)\\), which equals 18.

Do the multiplication first and only then subtract. Combining the signs early often turns a gain into a loss. The error is invisible once the intermediate step is skipped. Write the substitution line before simplifying.
