# Absolute value inequalities

## Distance From Zero

Absolute value measures distance from zero, so an inequality in absolute value describes a stretch of the number line. The statement \\(|x| < 4\\) asks which numbers lie closer to zero than 4 units.

Both directions count, so the answer is \\(-4 < x < 4\\). The single absolute value inequality splits into a compound one. Writing only \\(x < 4\\) would leave out every negative number that also satisfies the condition.

## Strict Absolute Value Inequalities

Shifted expressions work the same way after the centre is identified. For \\(|x - 3| < 2\\), the distance from 3 must be less than 2, so \\(1 < x < 5\\).

A greater-than sign points outward instead. The statement \\(|x - 3| > 2\\) gives \\(x < 1\\) or \\(x > 5\\), two rays rather than one interval. The direction of the inequality decides whether the answer is a middle stretch or two outer pieces.

## Counting Integer Solutions

Count integers only after the interval is correct. For \\(|x - 3| < 2\\) the solution is \\(1 < x < 5\\). The integers inside are 2, 3 and 4.

There are three of them. The endpoints 1 and 5 are excluded because the inequality is strict. Including either one would give four. Checking each candidate against the original absolute value is the safest way to confirm the count.
