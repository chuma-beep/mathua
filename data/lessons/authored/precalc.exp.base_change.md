# Changing the logarithm base

A logarithm in one base can be rewritten in another base by dividing two logarithms of the same new base. This makes any logarithm computable from natural or common logarithms.

## The formula

The logarithm of x in base b equals the logarithm of x in base c divided by the logarithm of b in base c.

## Choosing a base

Base ten suits hand calculation and base e suits calculus, so the choice is a convenience rather than a mathematical difference.

## Check by exponentiating

Raising the base to the computed value recovers the argument, which verifies the conversion.
