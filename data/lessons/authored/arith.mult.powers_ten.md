# Multiplying by powers of ten

Multiplying by powers of ten shifts every digit left by one place per zero.

## The idea

Multiplying by powers of ten shifts every digit left by one place per zero. The lesson keeps every quantity exact, so the answer can be checked by recomputing it from the stated values. Read the question for the quantity that is requested before choosing a formula. The same concept appears with different numbers, so the method matters more than a remembered answer.

## The computation

Move the digits one place for each zero in the power of ten. Work one small instance first, then repeat the same steps with the given values. Keep the units, signs and order of operations visible in the written work. If the calculation has a natural check, perform it before moving to the next question.

## Reading the result

The number of trailing zeros should equal the number of zeros in the power of ten. A useful final step is to compare the answer with the original quantities and with any obvious bound. If the result is a count or a length, it should be nonnegative. If it is a fraction or a sine, it should lie in its usual range. Record the answer in the form the question requests.

The three sections form one chain. The first names the object, the second performs the computation and the third checks the result. Practice asks one family from each section, so the three moves stay connected.
