# Local extrema

A local maximum is a value at least as large as every nearby value, and a local minimum is a value at most as large as every nearby value. They are the peaks and valleys of a graph.

## Local and absolute

A local extremum compares with nearby points only. An absolute extremum compares with the whole domain.

## Turning points

At a smooth turning point the graph changes direction, so a local extremum sits where the curve stops rising and starts falling, or the reverse.

## Counting extrema

A polynomial of degree n has at most n - 1 turning points, so it has at most n - 1 local extrema.

To check your understanding, compare nearby values, find where direction changes and use the degree.

A local extremum is a value of the function, while the input where it occurs is the location.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
