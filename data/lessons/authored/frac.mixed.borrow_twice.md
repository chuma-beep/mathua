# Borrowing twice with mixed numbers

A chain of subtractions can need a borrow at each step. Borrowing twice is the same rename applied twice: one whole becomes a fraction equal to one and the subtraction continues.

## The method

For each subtraction, write the fractions over a common denominator. If the fraction part of the minuend is smaller than the fraction part of the subtrahend, borrow one whole and add the denominator to the numerator. Then subtract. Repeat for the next term in the chain. For \(5\frac{1}{4} - 2\frac{3}{4}\) one borrow gives \(2\frac{1}{2}\). A third subtraction would need a third borrow, one step at a time. Borrowing changes only the written form, never the value of the minuend, so the chain stays exact.

## A worked example

Compute \(7\frac{1}{5} - 2\frac{3}{4} - 1\frac{1}{2}\). Over twentieths the first subtraction is \(7\frac{4}{20} - 2\frac{15}{20}\). Borrowing gives \(6\frac{24}{20} - 2\frac{15}{20} = 4\frac{9}{20}\). The second subtraction is \(4\frac{9}{20} - 1\frac{10}{20}\), which borrows again to give \(3\frac{29}{20} - 1\frac{10}{20} = 2\frac{19}{20}\).

## Checking the result

Add the two subtrahends back to the result. First \(2\frac{19}{20} + 1\frac{1}{2} = 2\frac{19}{20} + 1\frac{10}{20} = 3\frac{29}{20}\), which is \(4\frac{9}{20}\). Then \(4\frac{9}{20} + 2\frac{3}{4} = 4\frac{9}{20} + 2\frac{15}{20} = 6\frac{24}{20}\), which is \(7\frac{4}{20} = 7\frac{1}{5}\).

Each borrow is a rename and two subtractions need two of them.
