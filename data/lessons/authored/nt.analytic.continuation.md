# Continuing the zeta function

The zeta function is defined by a series only to the right of one. Analytic continuation extends it to the whole plane except a simple pole at one.

## Beyond the series

The series diverges for real parts at most one, but the function has a meromorphic continuation. Its only pole is simple, at s equal to one, with residue one.

## Values at negative integers

The continued function takes rational values at negative integers. Bernoulli numbers supply those values, and their denominators grow with the index.

## Trivial zeros

The continued function vanishes at every negative even integer. These trivial zeros are forced by the gamma factor, not by arithmetic.

To check your understanding, name the pole, use a Bernoulli number and locate a trivial zero.

Continuation is what makes the zeta function a global object, and the negative integers are where its values become visibly rational.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
