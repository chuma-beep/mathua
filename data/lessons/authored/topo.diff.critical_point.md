# Critical points of smooth functions

A critical point is where the derivative vanishes. For a Morse function the Hessian is nondegenerate, and each critical point carries an index.

## The index

The index of a nondegenerate critical point is the number of negative Hessian eigenvalues. A local maximum in dimension \(n\) has index \(n\).

## Height on the sphere

The height function on the round sphere has exactly two critical points, a maximum and a minimum. Both are nondegenerate, so the function is Morse.

## Morse data

The number of critical points of index \(k\) is written \(m_k\). For the height function on \(S^n\), \(m_0 = m_n = 1\) and every other count is zero.

To check your understanding, count negative eigenvalues, count the critical points and read the index counts.

Critical points carry an index that matches the homology.
