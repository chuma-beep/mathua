# Equations with variables on both sides

## Collecting Variables on One Side

When a variable appears on both sides, move all its terms to one side and all numbers to the other. Take \\(5x + 3 = 2x + 12\\). Subtract \\(2x\\) from both sides to get \\(3x + 3 = 12\\).

Then subtract 3, leaving \\(3x = 9\\), so \\(x = 3\\). The choice of side is free, but moving the smaller variable term keeps the coefficient positive, which makes the division easier to read.

## Equations With Variables Twice

Some equations carry the variable in more than two places. Combine like terms on each side first, then collect. Take \\(7x + 2 = 3x + 18\\). Subtracting \\(3x\\) gives \\(4x + 2 = 18\\). Subtracting 2 gives \\(4x = 16\\), so \\(x = 4\\).

If a side holds two variable terms, such as \\(2x + 5x\\), add them before moving anything. Collecting before combining usually produces a longer path to the same answer.

## Checking Both Sides

A solution to an equation with variables on both sides must make the two sides equal. Substitute \\(x = 3\\) into \\(5x + 3 = 2x + 12\\). The left side is 18 and the right side is also 18.

Check the second equation too: at \\(x = 4\\), both \\(7x + 2\\) and \\(3x + 18\\) equal 30. A mismatch means a sign error in the collection step, so redo that step before changing the answer.
