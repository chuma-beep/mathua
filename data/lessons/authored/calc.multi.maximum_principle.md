# The maximum principle

A nonconstant harmonic function attains its maximum and minimum on the boundary of its domain. An interior maximum forces the function to be constant.

## Boundary maximum

The maximum of a harmonic function on a closed disk is attained on the boundary circle. The same statement holds for the minimum. This is the maximum principle.

## Interior maximum test

If a harmonic function attains its maximum at an interior point, it must be constant on the connected domain. A nonconstant harmonic function cannot have an interior peak.

## The constant case

A constant function attains its maximum everywhere. It is the only harmonic function that can have an interior maximum. The boundary value and the interior value agree.
