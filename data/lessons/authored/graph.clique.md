# Clique number

A clique is a set of vertices that are all pairwise adjacent. The clique number is the size of the largest clique.

## Cliques

A clique of size 1 is a single vertex. A clique of size 2 is an edge. A clique of size k requires every pair among its k vertices to be joined by an edge.

## The clique number

The clique number is the maximum size of a clique. It is found by checking all vertex subsets in a small graph. The empty set is not counted.

## Maximum cliques

A maximum clique is a clique whose size equals the clique number. There can be several maximum cliques. Counting them requires checking every subset of that size.
