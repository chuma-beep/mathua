# Compound inequalities in one variable

## Between Two Bounds

A compound inequality traps the variable between two limits. The same operations apply to all three parts. Take \\(3 < 2x + 1 < 11\\). Subtract 1 across the whole statement to get \\(2 < 2x < 10\\).

Divide every part by 2, which is positive, so the directions stay unchanged: \\(1 < x < 5\\). The solution is one interval, not two. Any number inside it satisfies both original comparisons at once.

## Including the Endpoints

A strict inequality excludes its endpoint, while a version with a bar beneath the sign includes it. The statement \\(-2 \\le x \\le 3\\) includes both -2 and 3, so the interval is closed at both ends.

The length of that interval is \\(3 - (-2) = 5\\). Endpoints rarely change the arithmetic, but they decide whether a boundary value is an answer. Read the symbols before writing the final interval.

## Counting Integers in an Interval

Counting whole numbers inside an interval needs care at both ends. The integers satisfying \\(-2 \\le x \\le 3\\) are -2, -1, 0, 1, 2 and 3.

There are six of them, found from \\(3 - (-2) + 1 = 6\\). The extra 1 appears because both endpoints count. With a strict inequality at one end, omit that endpoint and subtract one from the count, which is where most counting errors begin.
