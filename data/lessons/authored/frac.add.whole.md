# Adding a fraction to a whole number

A whole number and a fraction can be added once the whole number is written with the same denominator as the fraction. The sum often lands above 1, so it may be written as a mixed number.

## The method

Write the whole number \(n\) as \(\frac{n}{1}\), then multiply both parts by the denominator \(b\) of the fraction. This gives \(\frac{nb}{b}\). Add the numerators and keep the denominator: \(n + \frac{a}{b} = \frac{nb + a}{b}\). The denominator \(b\) is nonzero throughout and the numerator may exceed the denominator.

## A worked sum

Add 2 and \(\frac{3}{5}\). Converting 2 to fifths gives \(\frac{10}{5}\), so the sum is \(\frac{10}{5} + \frac{3}{5} = \frac{13}{5}\). Since 13 is greater than 5, rewrite the result as \(2\frac{3}{5}\). A second case is \(4 + \frac{5}{8} = \frac{32}{8} + \frac{5}{8} = \frac{37}{8}\), which is \(4\frac{5}{8}\).

## Checking the result

Subtract the whole number from the sum: \(\frac{13}{5} - 2 = \frac{13}{5} - \frac{10}{5} = \frac{3}{5}\), which returns the original fraction. In decimal form the sum is 2.6 and \(2 + 0.6\) gives the same value. A sum whose fractional part is at least 1 signals a missed carry.

The whole number joins the fraction only after it wears the same denominator.
