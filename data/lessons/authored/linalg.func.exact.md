# Exact sequences of maps

An exact sequence is a chain of linear maps in which the image of each map equals the kernel of the next. Exactness packages kernels, images and quotients into one diagram.

## Exactness

At each interior node the image equals the kernel. At the ends, exactness says a map is injective or surjective.

## Dimension

For a finite exact sequence the alternating sum of dimensions is zero. This generalises rank-nullity and computes Euler characteristics.

## Splitting

A short exact sequence splits when a section exists. Over vector spaces every short exact sequence splits, so every quotient is a direct summand.

To check your understanding, check image equals kernel, write the alternating sum and find a section.

Exact sequences are the bookkeeping device that turns diagram chases into dimension counts.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
