# Partitions of an integer

A partition writes an integer as an unordered sum of positive integers. The partition function counts them and grows faster than any polynomial.

## The count

The partition function p of n counts unordered sums. Its values start one, one, two, three, five, seven, eleven and continue quickly.

## Distinct parts

Partitions into distinct parts are equinumerous with partitions into odd parts. Euler's identity is the generating function statement of that equality.

## The recurrence

Euler's pentagonal number theorem gives a recurrence for p of n. The recurrence uses only earlier values and generalised pentagonal numbers.

To check your understanding, list small partitions, count distinct partitions and name pentagonal numbers.

Partitions are unordered sums, and their generating function turns the count into a product over positive integers.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
