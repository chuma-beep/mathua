# Increasing and decreasing intervals

A function is increasing on an interval when larger inputs give larger outputs, and decreasing when larger inputs give smaller outputs. The intervals are read from the graph from left to right.

## Reading a graph

Follow the curve from left to right. Where it rises the function is increasing; where it falls it is decreasing.

## Turning points

A local maximum ends an increasing interval and begins a decreasing one. A local minimum does the reverse.

## Open intervals

Intervals of increase and decrease are written with open endpoints, because the turning point itself belongs to neither direction.

To check your understanding, move left to right, locate maxima and use open endpoints.

State intervals in input values, never in output values.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
