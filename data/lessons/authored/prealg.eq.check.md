# Checking a solution

## Substituting both sides

A solution is correct when substituting it into the equation makes the two sides equal. Replace x with the proposed value on the left and evaluate, then compare with the right side.

Use parentheses around the proposed value, especially when it is negative. The equation 2x + 1 = 7 with x = 3 gives 2(3) + 1 = 7, so the solution checks.

## Reading the difference

Subtract the right side from the left side after substitution. A difference of zero means the proposed value is a solution. A nonzero difference is the amount by which the check fails.

The sign of the difference tells which side is larger, but the size is what matters for the check. Report zero as a successful check.

## Solving and checking

Solve the equation independently by undoing the operations. Then substitute the solution into the original equation. The two methods should agree.

Checking is not a repeat of solving. Solving finds a candidate, and checking tests that candidate against the original equation.

A final check is to restate the answer in the units and context of the original question. If the result is plausible and the units match, the calculation is ready.
