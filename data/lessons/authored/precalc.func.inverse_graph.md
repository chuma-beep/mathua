# Reflecting graphs to invert them

The graph of an inverse function is the reflection of the original graph across the line y = x. Input and output trade places at every point.

## Swapping coordinates

A point (a, b) on the graph of f becomes (b, a) on the graph of its inverse, provided the inverse exists.

## Reflection

Reflecting across y = x turns a rising curve into a rising curve and swaps horizontal and vertical features, so asymptotes trade orientation.

## Restricting the domain

A function that is not one-to-one on its whole domain needs a restriction before an inverse graph can be drawn.

To check your understanding, swap x and y, draw the mirror line and test one-to-one.

The reflection is a geometric statement of the algebraic rule that composition returns the input.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
