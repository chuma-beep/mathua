# Tape diagrams for ratios

## Reading a tape diagram

A tape diagram shows equal units as matching rectangles. The number of rectangles is the number of parts, and every rectangle has the same value. Read the labels before you calculate. If three rectangles are marked 4 each, the diagram represents 3 x 4 = 12.

Keep the unit value separate from the number of units. A common mistake is to add the labels instead of multiplying the number of equal parts by the unit value. Write down both quantities before you choose an operation.

## Finding the total

When the unit value and the number of units are known, multiply them to find the total. If the diagram has five units and each unit is 6, the total is 30. The total is the whole that the tape represents.

When the total and the number of units are known, divide the total by the number of units. This recovers the value of one rectangle. Check by multiplying the unit value by the number of units and comparing with the total.

## Recovering a missing unit

Sometimes one section of the tape is unknown. Add the known sections first, then subtract their sum from the total. The remainder is the value of the missing section. Finally, divide by the unit value if the question asks for the number of units.

A second check is to rebuild the whole tape from the known and recovered sections. The rebuilt total must match the stated total. This catches an error in either the subtraction or the division.
