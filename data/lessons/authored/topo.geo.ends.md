# Ends of groups

The number of ends counts the unbounded components left after removing a large compact set. The line has two ends, the plane has one, and a tree has infinitely many.

## The line

The Cayley graph of \(\mathbb{Z}\) is a line. Removing a long interval leaves two unbounded rays, so the group has two ends.

## Higher dimensions

For \(n \ge 2\), the Cayley graph of \(\mathbb{Z}^n\) has one end. Removing a large ball leaves the outside connected, because there is room to walk around it.

## Free groups

A free group of rank at least two has infinitely many ends. Its Cayley graph is a tree whose complement of a ball has many unbounded branches.

To check your understanding, count the rays, read the end count and recognise the tree.

The number of ends separates the line from every higher-dimensional lattice.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller values and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
