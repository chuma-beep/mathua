# Principal values and branch cuts

A multivalued complex function needs a branch cut and a principal value to become single-valued.

## Choose the principal value

The principal argument lies between minus pi and pi. The principal logarithm uses that argument. The choice fixes the imaginary part of the logarithm.

## Locate the branch cut

The cut is where the chosen argument jumps. For the principal logarithm the cut is the negative real axis. Crossing the cut changes the value by a multiple of 2 pi i.

## Test continuity across the cut

Approach the cut from above and below. The limits differ by 2 pi i, so the principal value is discontinuous. A different branch can make the function continuous on the cut but not around the origin.
