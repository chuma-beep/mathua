# The page number

The page number is the book thickness of a graph, the minimum number of pages in a book embedding.

## The definition

The page number \(p(G)\) is the smallest number of pages in a book embedding with the vertices on a line. It equals one for outerplanar graphs and grows with the density of the graph.

## Planar graphs

Every planar graph has page number at most four, and some planar graphs need four. The bound is a classical theorem, and three pages do not suffice in general.

## Values

A path has page number one, a cycle has two and a complete graph \(K_n\) has \(\lceil n/2\rceil\). Every tree has page number one because it is outerplanar.

To check your understanding, count the pages, state the planar bound and read a path.

Page number turns a drawing question into a bookkeeping question about how many half-planes are needed.
