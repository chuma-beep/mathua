# The open mapping theorem

A nonconstant analytic function maps open sets to open sets. This rules out a nonconstant analytic function that collapses an open set to a point.

## Identify an open image

The image of an open disk under a nonconstant analytic map is open. A constant map has a one-point image, which is not open. The theorem is local and does not require a global inverse.

## Test the hypothesis

The function must be analytic on the open set and not constant there. A zero derivative at one point does not make the function constant. The theorem still applies near that point.

## Apply the theorem

Openness implies that a nonconstant analytic function cannot have a local maximum of its modulus. It also implies that zeros are isolated. The theorem is the source of many maximum-principle arguments.
