# Absolute value functions

The absolute value function returns the distance of its input from zero. Its graph is a V shape with a corner at the input where the expression inside vanishes.

## Piecewise form

The rule splits at the zero of the inner expression: one linear piece with a positive sign and one with a negative sign.

## Transformations

Shifts, stretches and reflections move the vertex and change the steepness of the two arms without changing the corner.

## Equations

An equation with one absolute value splits into two linear equations, one for each sign, and both must be checked in the original equation.

To check your understanding, find the zero, move the vertex and split the signs.

The corner is where the two pieces meet, so it is the natural anchor for every sketch.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
