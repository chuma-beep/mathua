# Parallel systems

A parallel system works when at least one component works, so redundancy raises reliability.

## Reliability

For independent components, the failure probability is the product of the component failure probabilities, so reliability is one minus that product.

## Two components

Two parallel components give \(R_1+R_2-R_1R_2\), which is at least each component's reliability.

## Limit

Adding components pushes reliability towards one, but with diminishing returns.
