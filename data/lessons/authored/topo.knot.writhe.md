# Writhe of a diagram

The writhe is the signed count of crossings in an oriented diagram. It is not a knot invariant, because a Reidemeister move can change it, but it corrects the bracket to a polynomial invariant.

## Signed count

A positive crossing contributes plus one and a negative crossing minus one. The writhe is the sum over all crossings.

## The trefoil

The standard positive trefoil diagram has three positive crossings. Its writhe is three.

## The range

A diagram with \(n\) crossings has writhe between \(-n\) and \(n\) in steps of two. The number of possible values is \(n + 1\).

To check your understanding, add the signs, count the positive crossings and count the possible values.

Writhe records the signs of the crossings.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller values and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
