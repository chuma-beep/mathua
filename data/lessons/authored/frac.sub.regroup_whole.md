# Regrouping a whole number to subtract

Subtracting a mixed number from a whole number needs one whole broken into fractional parts. Regrouping performs that borrow without changing the value.

## The method

Write the whole number \(n\) as \((n - 1) + \frac{b}{b}\), where \(b\) is the denominator of the fraction being subtracted. Then subtract the whole parts and the fraction parts separately. If the fractional part is still too small, borrow again from the whole part in the same way. The borrowed fraction equals one, so the value of the minuend never changes.

## A worked difference

Compute \(5 - 2\frac{3}{4}\). Rewrite 5 as \(4\frac{4}{4}\), then subtract the wholes to get 2 and the fractions to get \(\frac{1}{4}\). The result is \(2\frac{1}{4}\). A case with unlike denominators is \(3\frac{1}{3} - 1\frac{5}{6}\). Convert to sixths: \(3\frac{2}{6} - 1\frac{5}{6}\). Borrow one to get \(2\frac{8}{6}\), then subtract to obtain \(1\frac{3}{6} = 1\frac{1}{2}\).

## Checking the result

Add the difference back to the subtrahend. For the first case, \(2\frac{1}{4} + 2\frac{3}{4} = 5\), which is the original whole number. For the second, \(1\frac{1}{2} + 1\frac{5}{6} = 1\frac{3}{6} + 1\frac{5}{6} = 3\frac{2}{6} = 3\frac{1}{3}\). Both checks return the minuend, so the borrowing was correct.

Borrowing one whole is a rename, not a change in value.
