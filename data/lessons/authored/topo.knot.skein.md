# Skein relations

A skein relation computes an invariant by comparing three diagrams that differ at one crossing. The Alexander, Jones and HOMFLY polynomials each satisfy their own relation.

## The three diagrams

A skein relation involves three links: a positive crossing, a negative crossing and the smoothed diagram. Each relation therefore has three terms.

## The normalization

The unknot is assigned the value one. Every computation starts from the unknot and applies the relation one crossing at a time.

## The crossing count

A diagram with \(n\) crossings needs \(n\) applications of the relation. Each application reduces the crossing number by one in two of the three diagrams.

To check your understanding, count the diagrams, assign the unknot value and count the applications.

Skein relations turn a diagram into a recurrence.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller values and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
