# Nullclines

A nullcline is where one component of the vector field vanishes. The intersections of nullclines are the fixed points, and the signs between them give the direction of the flow.

## Definition

The horizontal nullcline is the set where the horizontal velocity is zero, so the flow is vertical there. The vertical nullcline is the set where the vertical velocity is zero, so the flow is horizontal there.

## Reading the signs

Each nullcline divides the plane into regions of fixed sign for one component. Testing one point in each region determines the direction of every arrow without solving the system.

## Fixed points and crossings

A fixed point lies where both components vanish, which is an intersection of the two nullclines. A tangential intersection is degenerate, and the linearisation there may have a zero eigenvalue.

To check your understanding, set one component to zero, pick a test point in a region and intersect the two nullclines.

Nullclines are the cheapest phase-portrait tool because they need only the algebraic signs of the two components.
