# Derivatives of absolute value functions

The absolute value function has a corner at zero. Its one-sided derivatives are minus one and one, so the derivative does not exist there.

## One-sided derivatives

For x greater than a, the absolute value is x minus a and the derivative is one. For x less than a, it is a minus x and the derivative is minus one. The two sides disagree at a.

## The corner

The graph changes direction at the vertex. A corner is not differentiable. The function is still continuous there.

## Differentiability

A function is differentiable at a point only when both one-sided derivatives exist and agree. The absolute value fails that test at its vertex. Away from the vertex it is differentiable.
