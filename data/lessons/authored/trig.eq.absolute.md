# Equations with absolute values of trigonometric functions

An absolute value in a trigonometric equation removes the sign of the ratio, so the equation splits into the ratio equal to a positive value and to its negative.

## Both signs of the inside

The split into two equations is the whole method. For \(|\sin x| = 1/2\) there are two equations
to solve. One is \(\sin x = 1/2\), giving 30 and 150 degrees; the other is \(\sin x = -1/2\),
giving 210 and 330 degrees. That is four solutions in a single turn.

## A full turn of solutions

Sine and cosine each reach a value twice per turn. The absolute value doubles that count to four.
For \(|\cos x| = \sqrt{3}/2\) the angles are 30, 150, 210 and 330 degrees. The extreme cases
collapse: \(|\sin x| = 1\) gives only 90 and 270 degrees, while \(|\cos x| = 1\) gives only 0 and
180 degrees, because a peak is touched once per half turn.

## The tangent case

Tangent is different, since it runs through every real value once per half turn. The equation
\(|\tan x| = 1\) splits into \(\tan x = 1\) at 45 and 225 degrees and \(\tan x = -1\) at 135 and
315 degrees, still four angles in a turn. A value above the range of the ratio gives nothing:
\(|\sin x| = 2\) has no solution, because no angle has a sine of magnitude 2.

Check the range of the ratio before splitting.
