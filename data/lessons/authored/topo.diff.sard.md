# Sard's theorem

Sard's theorem says the set of critical values of a smooth map has measure zero. Its dimension is bounded by the dimension of the source minus one.

## The dimension bound

For a smooth map from an \(m\)-manifold to an \(n\)-manifold, the critical values have dimension at most \(m - 1\). A smooth real-valued function on a surface has critical values of dimension at most one.

## Codimension

The critical set has codimension at least one in the source when the map is not constant on a component. That codimension is what makes the critical values negligible.

## Measure zero

The critical values form a set of measure zero in the target. Almost every regular value is therefore not critical, which is why transversality arguments start from Sard.

To check your understanding, subtract one from the source dimension, compute the codimension and state the measure.

Sard turns a dimension count into a genericity statement.
