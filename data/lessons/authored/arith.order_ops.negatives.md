# Order of operations with negatives and brackets

Order of operations with negatives and brackets combines sign rules with the bracket rule.

## The idea

Order of operations with negatives and brackets combines sign rules with the bracket rule. The lesson keeps every quantity exact, so the answer can be checked by recomputing it from the stated values. Read the question for the quantity that is requested before choosing a formula. The same concept appears with different numbers, so the method matters more than a remembered answer.

## The computation

Evaluate the bracketed group first and apply the sign rules to every product. Work one small instance first, then repeat the same steps with the given values. Keep the units, signs and order of operations visible in the written work. If the calculation has a natural check, perform it before moving to the next question.

## Reading the result

Recomputing with the sign rules should reproduce the same value. A useful final step is to compare the answer with the original quantities and with any obvious bound. If the result is a count or a length, it should be nonnegative. If it is a fraction or a sine, it should lie in its usual range. Record the answer in the form the question requests.

The three sections form one chain. The first names the object, the second performs the computation and the third checks the result. Practice asks one family from each section, so the three moves stay connected.
