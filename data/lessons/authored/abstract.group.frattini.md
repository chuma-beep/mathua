# The Frattini subgroup

The Frattini subgroup is the intersection of all maximal subgroups. Its elements are the non-generators, which no minimal generating set can contain.

## Definition

\(\Phi(G)\) is normal, and for a finite \(p\)-group it equals \(G^p[G,G]\).

## Non-generators

A set generates \(G\) together with a Frattini element exactly when it generates \(G\) without it.

## Quotient

For a cyclic group of order \(p^k\), the quotient by \(\Phi(G)\) has order \(p\).

To check your understanding, intersect maximals, remove one element and compute the order.
