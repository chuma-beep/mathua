# Why the denominator cannot be zero

A fraction records a division and division by zero has no value. The denominator therefore may be any number except zero.

## The definition

The fraction \(\frac{a}{b}\) asks for the number \(q\) with \(bq = a\). When \(b = 0\) the equation reads \(0q = a\). For \(a = 3\) no number \(q\) satisfies it, because every product with 0 is 0. For \(a = 0\) every number satisfies it, so the value is not unique. Neither case names a single number and both are excluded.

## An example

The expression \(\frac{5}{2-2}\) has no value. Watch the denominator shrink instead: \(\frac{5}{1} = 5\), \(\frac{5}{0.1} = 50\) and \(\frac{5}{0.01} = 500\). The quotient grows without bound as the denominator approaches zero, so no finite answer appears at zero. A denominator of 0.001 gives 5000, which confirms the trend rather than a limit.

## Why it matters

Every rational expression carries restrictions. The expression \(\frac{1}{x-3}\) is undefined at \(x = 3\), so 3 is not in its domain and a graph there has a vertical asymptote. Simplifying a fraction never removes the restriction, because the original denominator still excludes the value.

A zero denominator marks a missing input, not a small number.
