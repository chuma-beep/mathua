# Independent and dependent variables

## Input and Output

A relationship has an input and an output. The input is chosen or observed first. The output responds to it. If a job pays 12 dollars per hour, hours are the input and pay is the output.

For 5 hours the pay is \\(12 \\times 5 = 60\\) dollars. Naming the input before computing keeps the rule in one direction, which matters once the relationship is written as an equation.

## Choosing the Independent Variable

The independent variable is the one you control or measure freely. Time is usually independent, so distance travelled depends on it, not the reverse. A quantity bought is independent, so the total cost depends on it.

Ask which quantity can be set without waiting for the other. A van booked for 4 hours at 60 kilometres per hour covers 240 kilometres, so the time was set first and the distance followed. In a data table, the independent variable sits in the first column by convention. The dependent variable follows in the second. The axes follow the same order.

## Reading a Rule

A rule such as \\(y = 12x\\) states the output in terms of the input. Here \\(x\\) is the input and \\(y\\) is the output. Substituting 7.5 hours gives \\(y = 12 \\times 7.5 = 90\\) dollars.

Reading a rule backwards is a different task. It needs solving rather than substituting. A pay of 90 dollars corresponds to \\(x = 7.5\\) hours, which requires dividing rather than multiplying.
