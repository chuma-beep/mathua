# Parametric equations of a line

A parametric line starts at a point and moves along a direction. The parameter scales the direction vector.

## The form

The line (x,y)=(x0,y0)+t(dx,dy) passes through the base point and has direction (dx,dy).

## One parameter

A line needs one parameter, while a plane needs two, because each parameter adds one degree of freedom.

## Coordinates

Each coordinate is a separate linear expression in the same parameter t.

To check your understanding, read the base point, count the parameters and write x in t.

Parametric form describes motion along a line rather than the line as a single equation.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
