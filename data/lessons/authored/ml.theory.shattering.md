# Shattering

A set is shattered when the hypothesis class realises every labelling of it. Shattering is the combinatorial event behind the VC dimension.

## The labelings

A set of \(n\) points has \(2^n\) binary labellings. Shattering requires all of them to be realised.

## Realisation

A labelling is realised when some hypothesis agrees with it on the set. The hypothesis may disagree elsewhere.

## Monotonicity

A subset of a shattered set is shattered. Adding points can only destroy shattering, never create it.

To check your understanding, count the labellings, pick a hypothesis and take a subset.

Shattering is exhaustive labelling by a restricted class.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller numbers and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
