# The Erdos-Stone theorem

The Erdos-Stone theorem identifies the chromatic number as the only quantity that controls the asymptotic Turán density. Every forbidden graph with chromatic number \(r+1\) behaves like \(K_{r+1}\).

## The density

For a fixed graph \(H\) with chromatic number \(\chi(H)=r+1\), the extremal number satisfies \(\mathrm{ex}(n,H)=\left(1-\frac1r+O(1)\right)\frac{n^2}{2}\). Only the chromatic number of the forbidden graph enters.

## The Turán graph

The extremal example is the balanced complete \(r\)-partite graph. Its edge count is \(\left(1-\frac1r\right)n^2/2\) up to a lower-order correction from unequal part sizes.

## Bipartite exceptions

A bipartite forbidden graph has chromatic number two, so the theorem predicts density zero. Mantel and Kőnig give the exact order instead, which is why bipartite extremal problems need separate methods.

To check your understanding, read the chromatic number, choose the number of parts and recognise a bipartite forbidden graph.

Chromatic number sets the asymptotic density, and the balanced complete multipartite graph is the extremal construction.
