# Absolute-value inequalities on a number line

An absolute value measures distance. An inequality such as \(|x-h|\le r\) describes all points within a fixed distance of \(h\).

## Distance on a number line

The expression \(|x-h|\) is the distance from \(x\) to \(h\). The inequality \(|x-h|\le r\) keeps points at most \(r\) away.

The inequality \(|x-h|<r\) is the same interval without its endpoints. The strict and non-strict versions differ only at the boundary.

## The interval

The solution set of \(|x-h|\le r\) is \([h-r,h+r]\). Its center is \(h\) and its radius is \(r\).

The endpoints satisfy the inequality with equality. Values outside the interval are farther than \(r\) from the center.

## Counting integers

An interval \([h-r,h+r]\) with integer endpoints contains \(2r+1\) integers when \(h\) and \(r\) are integers.

Count both endpoints. For example, \([1,5]\) contains 1, 2, 3, 4 and 5, which is five values.

A greater-than inequality such as \(|x-h|>r\) describes the two rays outside the interval. Its solution is not a single interval.
