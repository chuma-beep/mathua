# The Brouwer fixed point theorem

The Brouwer fixed point theorem studies Brouwer's theorem guarantees a fixed point for a continuous self-map of a closed disk. The lesson separates the setup, the computation and the interpretation so practice can test each move.

## Fixed points

Fixed points starts from the defining objects. Identify what is given, state the governing relation and check the hypotheses before substituting numbers.

## Dimension

Dimension carries out the computation. Work with explicit small data, simplify exactly and keep the signs and dimensions consistent.

## The open disk

The open disk interprets the result and checks it against the definition. Compare with a second example and state what the answer means in the brouwer fixed point theorem.
