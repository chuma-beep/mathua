# Checking a solution to an inequality

## Testing a Value

Checking an inequality means substituting the value and comparing the two sides. For \\(3x - 1 < 8\\), test \\(x = 2\\). The left side is \\(3(2) - 1 = 5\\). Since 5 is less than 8, the value is a solution.

Substitution is the same as for an equation, but the conclusion depends on a comparison rather than on equality. Write the substituted statement in full before deciding, because a quick mental comparison is where sign errors survive.

## The Boundary Value

Solving the inequality gives the boundary. From \\(3x - 1 < 8\\), add 1 and divide by 3 to get \\(x < 3\\). The value 3 is the boundary. It is not a solution because the inequality is strict.

Substituting 3 gives \\(8 < 8\\), which is false. A boundary is a solution only when the sign includes equality, as in \\(x \\le 3\\). Test the boundary separately, since it is the one value the algebra treats specially.

## Accepting or Rejecting

A single test decides one candidate, so test each value that matters. Take \\(x = 4\\) for the same inequality. The left side is 11. Since 11 is not less than 8, the value 4 is rejected.

Then test \\(x = 0\\). The left side is -1, which is less than 8, so 0 is accepted. Avoid testing only a value that works, because a rejected candidate is the one that exposes a reversed inequality sign.
