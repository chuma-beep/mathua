# Random permutations

A uniformly random permutation has a cycle structure described by the Stirling numbers and a typical number of cycles near \(\log n\).

## Cycles

The number of permutations of \(n\) elements with \(k\) cycles is the unsigned Stirling number of the first kind.

## Fixed points

The expected number of fixed points is one for every \(n\), and the count converges to a Poisson law.

## Longest cycle

The longest cycle has length about a constant fraction of \(n\), with a known limiting distribution.

To check your understanding, count permutations by cycles, use linearity and scale by n.

Random permutations are cycle structures with logarithmic cycle counts.
