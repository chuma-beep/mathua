# Information criteria for model selection

Information criteria compare models by balancing fit against complexity.

## Compute AIC

AIC is twice the negative log-likelihood plus twice the number of parameters. A smaller AIC is better. The penalty discourages an unnecessarily large model.

## Compute BIC

BIC uses the same fit term but a penalty of log n times the number of parameters. It penalises complexity more strongly for large samples. The model with the smaller BIC is preferred.

## Compare two models

Compare the criteria on the same data and the same response. A difference of a few points is weak evidence. The comparison is relative, not an absolute goodness-of-fit test.
