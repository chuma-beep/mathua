# Evaluating expressions with two variables

## Substituting two values

An expression with two variables needs a value for each variable. Replace each letter with its value and keep the operation signs. Use parentheses around negative values so the signs are clear.

Substitute both values before doing any arithmetic. Changing one value at a time makes it easy to lose track of which letter has been replaced.

## Simplifying the result

Follow the order of operations after substitution. Multiply before adding or subtracting. If the expression has a constant term, add it last.

Check the signs carefully. A negative value squared is positive, but a negative value multiplied by a positive coefficient is negative. Parentheses prevent both mistakes.

## Recovering a variable

If the value of the expression and one variable are known, substitute them and solve for the other variable. Move the known terms to one side and divide by the remaining coefficient.

Check the recovered value by substituting both variables into the original expression. The result must equal the stated value.

A final check is to restate the answer in the units and context of the original question. If the result is plausible and the units match, the calculation is ready.
