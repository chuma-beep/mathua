# Crossing number

## Drawings and crossings

The crossing number is the smallest number of crossings in any drawing of a graph in the plane. Edges are allowed to meet only at vertices in a planar drawing.

A graph has crossing number zero exactly when it is planar. A positive crossing number means every drawing has at least that many crossings.

## Small complete graphs

The complete graph K_5 has crossing number one. K_6 has crossing number three and K_7 has crossing number nine. These values are established by explicit drawings and lower bounds.

The complete bipartite graph K_3,3 also has crossing number one. It is the other basic obstruction to planarity.

## Claimed drawings

A claimed drawing with more crossings than the crossing number is valid but not optimal. Subtract the crossing number to find how many crossings are unnecessary.

A claimed drawing with fewer crossings than the known crossing number cannot be correct. Check the drawing for an accidental edge crossing or a missing vertex.

A final check is to restate the answer in the units and context of the original question. If the result is plausible and the units match, the calculation is ready.
