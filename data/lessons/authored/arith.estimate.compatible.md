# Estimating quotients with compatible numbers

Estimating quotients with compatible numbers replaces the divisor with a nearby friendly number.

## The idea

Estimating quotients with compatible numbers replaces the divisor with a nearby friendly number. The lesson keeps every quantity exact, so the answer can be checked by recomputing it from the stated values. Read the question for the quantity that is requested before choosing a formula. The same concept appears with different numbers, so the method matters more than a remembered answer.

## The computation

Replace the divisor with the nearest multiple of ten or one hundred that divides the dividend exactly. Work one small instance first, then repeat the same steps with the given values. Keep the units, signs and order of operations visible in the written work. If the calculation has a natural check, perform it before moving to the next question.

## Reading the result

The estimate should be close to the exact quotient and easy to compute mentally. A useful final step is to compare the answer with the original quantities and with any obvious bound. If the result is a count or a length, it should be nonnegative. If it is a fraction or a sine, it should lie in its usual range. Record the answer in the form the question requests.

The three sections form one chain. The first names the object, the second performs the computation and the third checks the result. Practice asks one family from each section, so the three moves stay connected.
