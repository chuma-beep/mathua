# DBSCAN

DBSCAN studies DBSCAN forms clusters from dense neighbourhoods and labels the rest as noise. The lesson separates the setup, the computation and the interpretation so practice can test each move.

## Core points

Core points starts from the defining objects. Identify what is given, state the governing relation and check the hypotheses before substituting numbers.

## Clusters

Clusters carries out the computation. Work with explicit small data, simplify exactly and keep the signs and dimensions consistent.

## Noise

Noise interprets the result and checks it against the definition. Compare with a second example and state what the answer means in dbscan.

A complete answer names the relation, substitutes the data and states the result in the language of the problem. When a second method is available, compare the two results before moving on.
