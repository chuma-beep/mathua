# Limits with absolute values

An absolute value changes formula at its zero. A limit there must be checked from both sides.

## Left and right formulas

For \(x<a\), \(|x-a|=-(x-a)\). For \(x>a\), \(|x-a|=x-a\). The quotient therefore has different constant values on the two sides.

Each one-sided limit is easy once the absolute value is removed.

The point \(x=a\) itself is not in the domain of the quotient, so the function value cannot settle the limit.

## When the two-sided limit fails

If the left and right limits differ, the two-sided limit does not exist. A jump discontinuity is the typical picture.

The function value at the point, if defined, does not repair a mismatch between the one-sided limits.

A graph of the quotient shows two horizontal rays with a gap at the vertical line \(x=a\).

## Sign and direction

The quotient \(|x-a|/(x-a)\) is -1 on the left and 1 on the right. The sign records the direction of approach.

Reversing the order in the denominator would reverse both signs, so keep the denominator consistent with the definition.

The quotient is a compact way to ask which side of \(a\) a point lies on.
