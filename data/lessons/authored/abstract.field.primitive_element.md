# The primitive element theorem

Every finite separable extension is generated by one element. That element is primitive for the extension.

## Statement

A finite separable extension has a single generator whose minimal polynomial has degree equal to the extension degree.

## Conjugates

A degree-n extension has n embeddings into an algebraic closure, one for each conjugate.

## Separability

The theorem fails without separability, which is why perfect fields are the natural setting.

To check your understanding, find a generator, count embeddings and check distinct roots.

One element can generate the whole separable extension.
