# Limits of piecewise functions

A piecewise function changes its rule at a boundary. Its limit there depends on what each side approaches, not on the value assigned at the boundary. The two one-sided limits decide everything.

## Approach from each side

Evaluate the left-hand limit with the rule that governs inputs below the boundary. Evaluate the right-hand limit with the rule above it. The boundary value itself is irrelevant to either limit, because a limit describes the approach, not the arrival.

If both one-sided limits agree, the two-sided limit exists and equals that common value. If they disagree, the limit does not exist, even though both one-sided limits do. A jump in the graph is exactly this disagreement.

## The boundary itself

The function may be defined at the boundary, undefined there, or defined with a value that matches neither side. None of those choices changes the limit. They only affect continuity.

Continuity at the boundary requires three things: the limit exists, the function is defined there, and the two agree. A removable gap can be repaired by redefining one point; a jump cannot be repaired by changing a single value.

## Choosing a constant

Many piecewise problems ask for the constant that makes the pieces meet. Compute both one-sided limits, set them equal, and solve for the unknown. The result is the value that removes the jump.

Check the answer by substituting it back into both branches. If the two heights now match, the function is continuous. If they do not, the algebra or the branch assignment is wrong.
