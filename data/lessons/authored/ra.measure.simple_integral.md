# The integral of a simple function

A simple function takes finitely many values on measurable sets. Its integral is the sum of each value times the measure of the set where it is attained.

## Simple functions

A simple function is a finite linear combination of indicator functions of measurable sets. It is the first class of functions for which the Lebesgue integral is defined directly. The sets are usually taken disjoint when the representation is used for integration. The measure of the support is the measure of the set where the function is nonzero. It is not the same as the integral: the integral weights each level set by its measure, so a function equal to 2 on a set of measure 3 has integral 6 while its support has measure 3.

## Integrating over disjoint intervals

If a simple function equals c1 on one interval and c2 on a disjoint interval, its integral is c1 times the length of the first plus c2 times the length of the second. This is the finite version of the general formula. The intervals do not need to have equal length.

## Counting measure

On a finite set with counting measure, the integral of a function is the sum of its values with the prescribed weights. The weights play the role of lengths. A simple function on finitely many atoms therefore reduces to a finite sum.
