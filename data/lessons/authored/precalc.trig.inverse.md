# Inverse trigonometric functions

Inverse trigonometric functions return an angle for a given ratio. Each has a restricted range so that it is one-to-one.

## Principal ranges

Arcsine returns angles from minus pi over two to pi over two, arccosine from zero to pi and arctangent from minus pi over two to pi over two.

## Composition

The composition of a trigonometric function with its inverse returns the input only inside the principal range. Outside it, the result is the reference angle.

## Solving equations

An inverse function gives one solution. The periodic symmetry of the trigonometric function supplies the others.

To check your understanding, recall the range, apply the inverse and find the principal value.

The restricted range is what makes the inverse a function rather than a relation.
