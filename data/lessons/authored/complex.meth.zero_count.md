# Counting zeros

The argument principle counts zeros minus poles as the change in argument divided by 2π.

## Principle

For a meromorphic function, the winding of its image equals the number of zeros minus the number of poles inside the contour.

## Polynomials

A polynomial has no poles, so the count reduces to its zeros, and outside the roots the count is zero.

## Entire functions

An entire function with no zeros gives a zero count for every contour, as \(e^{z}\) does.

To check your understanding, count zeros, use the degree and test for zeros.

The argument principle converts an analytic count into a geometric winding.
