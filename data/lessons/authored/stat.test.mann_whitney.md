# The Mann-Whitney U test

The Mann-Whitney U test compares two independent groups using ranks.

## Rank the pooled sample

Combine the two groups and rank all observations. Ties receive average ranks. Keep the group labels so the ranks can be split back.

## Compute U

Sum the ranks in group one and subtract the minimum possible sum. The result is U1. The complementary value U2 is the total number of pairs minus U1.

## Read the test conclusion

Compare the smaller U with a table or a normal approximation. A small U suggests the groups differ in location. The test is distribution-free under the null hypothesis.
