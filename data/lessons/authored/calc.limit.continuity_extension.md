# Removable discontinuities and continuous extensions

A removable discontinuity has a finite limit that differs from the function value or is not assigned. The continuous extension fills the hole with that limit.

## Removable discontinuity

Factor and cancel the common factor. The simplified expression gives the limit at the missing point. The original function may be undefined there.

## The extension

Define the function at the missing point to equal the limit. The new function is continuous at that point. The extension changes only the single point.

## Classification

A finite limit with a missing or different value is removable. A jump or an infinite limit is not removable. The classification depends on the one-sided limits.
