# Annuities

An annuity is a sequence of equal payments made at regular intervals. Its future value is a geometric series whose ratio is the periodic growth factor.

## Future value

Each payment accumulates interest for a different number of periods, so the future value is the payment times a geometric sum.

## The sum

The geometric sum of the accumulation factors simplifies to a single fraction involving the growth factor and the number of payments.

## Present value

Discounting every payment to the start gives the present value, which is the future value divided by the growth factor raised to the number of periods.

To check your understanding, accumulate each payment, use the geometric sum and discount each payment.

Draw the payment timeline, because the number of interest periods per payment is the usual source of error.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
