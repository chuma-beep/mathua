# Partial fractions

Distinct linear factors give constant numerators, and the coefficients are residues.

## Form

A proper rational function with distinct poles splits as \(\sum A_{k}/(z-c_{k})\) with constant numerators.

## Coefficients

Multiplying by \(z-c_{k}\) and setting \(z=c_{k}\) returns \(A_{k}\), the residue at that pole.

## Sum

The sum of the coefficients is the value the rational function would have at infinity, often zero.

To check your understanding, write the sum, isolate one coefficient and add the coefficients.

Partial fractions and residues are the same decomposition viewed twice.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller values and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
