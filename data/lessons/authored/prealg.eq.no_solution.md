# Equations with no solution or infinitely many solutions

## One Solution

Most linear equations have exactly one value that makes them true. For \\(4x + 1 = 9\\), subtract 1 to get \\(4x = 8\\), then divide by 4 for \\(x = 2\\).

The variable survives the collection step with a nonzero coefficient. Dividing by that coefficient produces the single answer. Substitute it back to confirm that both sides agree at 9. A single solution is the ordinary case, not the only possible one.

## No Solution

Sometimes the variable cancels from both sides and leaves a false statement. Take \\(2x + 5 = 2x + 7\\). Subtract \\(2x\\) and the equation becomes \\(5 = 7\\), which is false for every value of x.

No number can make a false statement true, so the equation has no solution. Spot the case by watching for the variable disappearing entirely, then read the leftover statement literally instead of forcing an answer.

## Infinitely Many Solutions

Other equations reduce to a true statement that mentions no variable. For \\(3(x + 2) = 3x + 6\\), distributing gives \\(3x + 6 = 3x + 6\\). Subtracting \\(3x\\) leaves \\(6 = 6\\), which holds always.

Every number is a solution, so the equation is an identity. The two sides are the same expression written differently, which is why no single value can be singled out. Distinguishing this case from the previous one is simply a matter of whether the leftover statement is true or false.
