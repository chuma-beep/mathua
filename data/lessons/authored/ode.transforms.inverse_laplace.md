# Inverse Laplace transforms

The inverse Laplace transform recovers a time function from its transform. Linearity and a short table cover most elementary cases.

## Match a transform pair

Recognise a transform that appears in the standard table. The inverse is the corresponding time function. Constants and powers of s are the most common entries.

## Invert a linear combination

Split the transform into a sum of table entries. Apply the inverse to each term separately. The result is the same linear combination in the time domain.

## Invert a shifted transform

A shift in s corresponds to multiplication by an exponential in time. Rewrite the transform with the shift separated from the table entry. The inverse is the table function times the exponential.

A complete answer states the governing relation, substitutes the given values and reads the result in the language of the problem. Where a second method is available, compare the two results before moving to the next question.
