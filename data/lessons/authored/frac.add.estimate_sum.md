# Estimating a sum of fractions

An estimate for a sum of fractions comes from rounding each fraction to a nearby benchmark. The estimate gives the size of the answer before any common denominator is written.

## The method

Replace each fraction by 0, \(\frac{1}{2}\) or 1, whichever is nearest. Add the replacements. Record whether each rounding went up or down, because the direction of the errors says whether the estimate is above or below the true sum.

## A worked sum

Estimate \(\frac{5}{8} + \frac{4}{9}\). The first fraction is close to \(\frac{1}{2}\) and the second is slightly below \(\frac{1}{2}\), so the estimate is 1. The exact sum is \(\frac{45}{72} + \frac{32}{72} = \frac{77}{72}\), which is \(1\frac{5}{72}\) and about 1.069. The estimate is low by roughly 0.07, which is the small amount by which the rounded values fell short.

A second case is \(\frac{11}{12} + \frac{7}{8}\). Both round up to 1, so the estimate is 2, while the exact sum is \(\frac{22}{24} + \frac{21}{24} = \frac{43}{24}\), about 1.79. Here both roundings went up, so the estimate is above the truth.

## Checking the result

Bracket the sum with one fraction rounded down and the other rounded up. For the first case, \(\frac{1}{2} + \frac{1}{2} = 1\) is a lower bracket and \(1 + \frac{1}{2} = 1.5\) is an upper bracket and 1.069 sits between them.

An estimate is trustworthy when its error direction is known.
