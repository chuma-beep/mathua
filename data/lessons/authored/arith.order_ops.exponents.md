# Order of operations with exponents

Order of operations with exponents evaluates powers before multiplication and addition.

## The idea

Order of operations with exponents evaluates powers before multiplication and addition. The lesson keeps every quantity exact, so the answer can be checked by recomputing it from the stated values. Read the question for the quantity that is requested before choosing a formula. The same concept appears with different numbers, so the method matters more than a remembered answer.

## The computation

Compute each power first, then multiply, and finish with addition and subtraction. Work one small instance first, then repeat the same steps with the given values. Keep the units, signs and order of operations visible in the written work. If the calculation has a natural check, perform it before moving to the next question.

## Reading the result

Recomputing the powers before the other operations should reproduce the same value. A useful final step is to compare the answer with the original quantities and with any obvious bound. If the result is a count or a length, it should be nonnegative. If it is a fraction or a sine, it should lie in its usual range. Record the answer in the form the question requests.

The three sections form one chain. The first names the object, the second performs the computation and the third checks the result. Practice asks one family from each section, so the three moves stay connected.
