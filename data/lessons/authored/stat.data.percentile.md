# Percentiles

The kth percentile is a value below which about k percent of the data fall, so the 90th percentile of a score distribution is the mark that nine tenths of the candidates fall short of.

## The nearest-rank rule

One common definition takes the nearest rank. For \(n\) ordered values, compute \(k n / 100\), round up to a whole number and take the value at that position. With 40 ordered values the 25th percentile sits at \(0.25 \times 40 = 10\). With 37 values the 90th percentile sits at \(0.9 \times 37 = 33.3\), which rounds up to 34.

## Reading a percentile

A percentile is a position, not a percentage score. A learner at the 80th percentile scored better than about 80 percent of the group and worse than the other 20 percent; that raw score could be 62 out of 100. In a group of 250 candidates the 80th percentile is at position \(0.8 \times 250 = 200\).

## Counting below

The count below a percentile is recovered by multiplying. If 480 learners sit a test and the 35th percentile is 41 marks, then about \(0.35 \times 480 = 168\) learners scored below 41. The word about matters because ties and the rounding rule move the answer by a few cases, so a check against the raw data is worth the minute it takes.

A percentile is therefore a statement about rank in a particular sample; it should be quoted with the sample size that gave it meaning.
