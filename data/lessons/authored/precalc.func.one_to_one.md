# One-to-one functions

A one-to-one function gives a different output for every input. The horizontal-line test turns that definition into a geometric check.

## The horizontal-line test

A function is one-to-one when every horizontal line meets its graph at most once. A line that meets the graph twice gives two inputs with the same output. Linear and cubic functions with nonzero leading terms pass the test while even powers fail it.

## Finite tables

A finite table is one-to-one exactly when its output column has no repeated value. Compare the listed outputs directly rather than inferring a shape from a graph. Four distinct outputs give four distinct inputs.

## Restricting the domain

A function that fails the horizontal-line test can become one-to-one after restricting its domain. A quadratic restricted to a nonnegative interval is increasing there. The restricted function then has an inverse.

Practice connects the three sections: state the relation, carry out the computation and interpret the result. A second method is a useful check when one is available.
