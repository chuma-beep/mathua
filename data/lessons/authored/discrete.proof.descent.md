# Infinite descent

Infinite descent proves a statement by assuming a smallest counterexample and constructing a smaller one. The contradiction is with well-ordering, not with the statement directly.

## Well-ordering

Every nonempty set of positive integers has a least element. Descent uses that least element as the starting point.

## The descent step

From a counterexample the proof derives a strictly smaller counterexample. The construction must preserve the property that makes the example a counterexample.

## The contradiction

The smaller counterexample contradicts minimality. Hence no counterexample exists and the statement holds for all positive integers.

To check your understanding, assume a counterexample, construct a smaller witness and compare with minimality.

Descent is minimal-counterexample induction read backwards. The creative work is always the step that produces a smaller witness.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
