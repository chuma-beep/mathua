# Normalizers and centralizers

The normalizer of a subgroup is the largest subgroup in which it is normal, and the centralizer of an element is the set of elements that commute with it.

## Definitions

\(N_G(H)=\{g\in G: gHg^{-1}=H\}\) contains \(C_G(H)=\{g\in G: gh=hg \text{ for all } h\in H\}\).

## Class size

The conjugacy class of an element has size equal to the index of its centralizer.

## Centres

The centre is the intersection of all centralizers, and in the symmetric group only the identity is central.

To check your understanding, write the normalizer, use orbit-stabilizer and intersect centralizers.

Normalizers measure how far a subgroup is from being normal, and centralizers measure commutativity.
