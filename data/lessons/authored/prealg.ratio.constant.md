# The constant of proportionality

## Finding the constant

A proportional table pairs each input with an output that is a fixed multiple of the input. That fixed multiple is the constant of proportionality. Divide any output by its matching input to find it, provided the input is not zero.

Use the same constant for every row. If one row gives a different quotient, the table is not proportional. A quick check is to multiply each input by the constant and compare the result with the output.

## Using the constant

Once the constant is known, multiply it by a new input to predict the output. To recover an input from an output, divide the output by the constant. These two operations are inverses of each other.

Keep the units attached to the constant. A constant of 3 dollars per item means each item costs 3 dollars, not that the total is always 3. The units explain why multiplication and division are the correct operations.

## Checking proportionality

A table is proportional only when every pair has the same quotient. Check at least two rows, and check the row with the largest values because rounding errors are easier to see there.

A graph of a proportional relationship is a straight line through the origin. A straight line that misses the origin is not proportional. The constant is the slope of that line.
