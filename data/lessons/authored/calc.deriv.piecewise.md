# Derivatives of piecewise functions

A piecewise function can have a derivative on each piece, but differentiability at the join requires more than matching slopes.

## One-sided derivatives

Differentiate each branch separately. The left-hand derivative at the join uses the left branch, and the right-hand derivative uses the right branch.

A corner appears when the one-sided derivatives differ. The function is continuous there but not differentiable.

A jump can occur even when the slopes are equal, so check the values separately.

## Differentiability at the join

Differentiability requires continuity first. The two branch values at the join must agree.

Then the two one-sided derivatives must also agree. Matching slopes alone is not enough if the graph has a jump.

Both conditions are local to the join, so the rest of each branch can be differentiated normally.

## Choosing a parameter

A parameter in one branch can be chosen to make the slopes match. Solve the derivative equality at the join.

After finding the parameter, verify continuity as well. A slope match without a value match still fails.

Two parameters may be needed when both the value and the slope are free.
