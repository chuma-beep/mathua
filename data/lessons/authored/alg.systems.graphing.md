# Solving systems by graphing

Two linear equations describe two lines. A solution is a point that lies on both lines at once, so the graph turns an algebraic problem into a question about where two lines cross. Graphing is the most direct way to see whether a system has one solution, none, or infinitely many.

## Where two lines meet

Most pairs of lines cross exactly once. The coordinates of that crossing satisfy both equations, which is what makes them a solution. Read the horizontal coordinate first, then the vertical coordinate. The order matters: \((3,-2)\) is not the same point as \((-2,3)\).

A graph gives an approximate answer unless the crossing sits exactly on grid lines. Use the picture to locate the point, then substitute both coordinates into both equations to confirm. Substitution is the proof; the picture is the search.

## Reading a graph accurately

Draw each line from two points, not from one point and a guessed slope. The intercepts are often convenient. If a line is written in slope-intercept form \(y=mx+b\), start at \(b\) on the vertical axis and move according to the slope.

A ruler helps because a small drawing error becomes a large coordinate error. When the crossing is between grid lines, say so and use algebra to find the exact value. A graph that suggests \((2.5,1.5)\) should lead to a check with fractions, not to a rounded guess.

## When the picture disagrees

Parallel lines never meet, so the system has no solution. The same line drawn twice meets itself everywhere, so the system has infinitely many solutions. These are not failures of graphing; they are the three possible shapes of a linear system.

If the lines appear to cross but substitution fails, the drawing is wrong. Recompute two points per line. If substitution gives a contradiction, the lines are parallel. If it gives an identity, the equations describe the same line.
