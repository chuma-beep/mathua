# Writing a function rule from a table

## Rules From a Table

A table of paired inputs and outputs often hides a linear rule. Compare consecutive outputs while the inputs rise by one. A table with pairs (1, 5), (2, 7) and (3, 9) has outputs that grow by 2 each time.

A constant difference is the signature of a linear rule. That difference becomes the multiplier on the input. When the outputs jump by unequal amounts, the rule is not linear and this method does not apply.

## The Multiplier

The multiplier is the change in output for each single step in input. Here the step is 1 and the change is 2, so the rule starts as \\(2x\\). Test it at the first input: \\(2 \\times 1 = 2\\), but the table says 5.

The gap between the test value and the table value is constant, which is why a single correction fixes every row. Subtract the test value from the table value to find that correction, here \\(5 - 2 = 3\\).

## The Starting Value

The correction is the output when the input is zero, so it is the starting value of the rule. With a multiplier of 2 and a correction of 3, the rule is \\(y = 2x + 3\\).

Verify against a row that was not used to build the rule. At \\(x = 3\\) the rule gives \\(6 + 3 = 9\\), which matches the table. Two agreeing rows make an arithmetic slip unlikely. Every row must agree.
