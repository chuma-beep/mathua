# Nonconstructive proofs

A nonconstructive proof establishes that an object exists without producing it. Counting arguments and contradiction are the usual routes.

## Counting

If more objects have a property than fail it, one with the property must exist. The proof never names that object.

## Contradiction

Assuming no object exists leads to a contradiction. The argument proves existence but gives no witness.

## The cost

A nonconstructive proof cannot be run. It may still establish a bound or decide a question that a constructive search could not.

To check your understanding, count both classes, assume nonexistence and note the missing witness.

Nonconstructive existence is a valid mathematical result with no algorithm attached. The distinction matters when the object is meant to be computed rather than merely known to exist.
