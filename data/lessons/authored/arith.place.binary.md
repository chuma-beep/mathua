# Binary place value

Binary writes a number with only zero and one, using powers of two as place values. It is the place-value system computers use.

## Powers of two as places

The places in a binary numeral are one, two, four, eight and so on. Each digit says whether that power is present. Reading from the right, the place values double at each step.

## Converting a numeral

Multiply each one bit by its place value and add the results. For example, 1011 has ones in the eight, two and one places, so its value is eleven. The leading one is the largest power of two not exceeding the number.

## Counting one bits

The number of one bits is the number of powers of two in the expansion. It is also called the popcount. Repeatedly halving the number and adding the remainders counts the same bits.
