# Piecewise function graphs

A piecewise function is several rules sharing one domain. Each rule owns an interval, and the graph is the pieces placed side by side. Reading the graph means first deciding which rule applies, then evaluating that rule.

## One rule at a time

The input decides the branch. Check the input against each condition before doing any arithmetic. If \(x<2\), use the rule written for \(x<2\); if \(x\ge 2\), use the other rule. The condition is about the input, not about the output or the shape of the graph.

A common mistake is to evaluate the more familiar formula. The familiar formula has no priority. The inequality is the instruction, and it must be checked every time.

## Reading the boundary

At the boundary the two pieces may meet, or they may leave a gap. A solid dot marks the value that belongs to the function; an open dot marks a value that is approached but not taken. The definition usually gives the boundary to the rule with \(\le\) or \(\ge\).

Continuity at the boundary requires both one-sided pieces to arrive at the same height. If they arrive at different heights, the graph jumps. The function is still defined, but it is not continuous there.

## The graph tells the story

A piecewise graph can model a parking fee that changes after the first hour, a tax bracket, or a shipping rate that drops above a weight. The break is part of the model, not an error in the drawing.

To evaluate, find the input on the horizontal axis, move vertically to the piece that owns that input, and read the height. To work backward, find the height and collect every input whose piece reaches it. A piecewise function can therefore have several inputs with the same output.
