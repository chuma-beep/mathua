# Cluster points and subsequential limits

A cluster point of a sequence is a value that a subsequence approaches. The set of cluster points records every possible limit of a convergent subsequence.

## Cluster points

A real number L is a cluster point when some subsequence converges to L. The sequence need not converge to L, and L need not appear as a term. A constant sequence has one cluster point, while a sequence that cycles through k distinct values has exactly k.

## Two subsequences

If the even terms approach A and the odd terms approach B, both A and B are cluster points. A sequence with more than one cluster point cannot converge. The largest and smallest cluster points are the limit superior and limit inferior.

## Alternating sequences

The sequence C plus (-1)^n D alternates between C plus D and C minus D. Both values are cluster points. The smaller one is C minus D when D is positive. The oscillation has size 2D and never disappears.
