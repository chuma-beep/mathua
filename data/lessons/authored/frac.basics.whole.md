# Whole numbers written as fractions

Every whole number can be written as a fraction with denominator 1 and in infinitely many other ways. The fraction notation then covers the whole numbers without a separate rule.

## The definition

For a whole number \(n\) and a nonzero whole number \(k\), the identity \(n = \frac{n}{1} = \frac{kn}{k}\) holds. Multiplying the numerator and the denominator by the same number does not change the quotient, because dividing \(kn\) by \(k\) returns \(n\). The denominator must stay nonzero, so \(k\) is positive here. This is why 3 can be written as \(\frac{3}{1}\), as \(\frac{6}{2}\) or as \(\frac{12}{4}\).

## An example

To write 5 with denominator 3, multiply both parts of \(\frac{5}{1}\) by 3 and obtain \(\frac{15}{3}\). That form is useful in a subtraction: \(5 - \frac{4}{3} = \frac{15}{3} - \frac{4}{3} = \frac{11}{3}\), which is \(3\frac{2}{3}\). The same whole number also equals \(\frac{10}{2}\) and \(\frac{20}{4}\) and each form names the same point on the number line.

## Why it matters

Sums and differences of a whole number and a fraction need one denominator and writing the whole number as a fraction supplies it. Writing 2 as \(\frac{10}{5}\) lets it join \(\frac{3}{5}\) in one sum. The rewrite also places whole numbers among the fractions rather than beside them, so one set of rules covers both.

A whole number is a fraction whose denominator divides its numerator exactly.
