# Domination number

A dominating set is a set of vertices whose closed neighbourhoods cover the whole graph. The domination number is the smallest such set.

## Closed neighbourhoods

The closed neighbourhood of a vertex contains the vertex and all of its neighbours. A set dominates when the union of its closed neighbourhoods is the whole vertex set. Isolated vertices must therefore be included in the set.

## The domination number

The domination number is the minimum size of a dominating set. It is at least 1 and at most the number of vertices. For a small graph it is found by checking every subset.

## Constrained domination

Sometimes a dominating set must contain a specified vertex. The minimum size can increase when that constraint is added. The answer is the smallest dominating set that contains the required vertex.
