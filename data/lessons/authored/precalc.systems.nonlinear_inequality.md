# Nonlinear inequalities in two variables

A nonlinear inequality describes a region rather than a curve. The boundary curve and a test point determine the region.

## The boundary

Replace the inequality by an equation to draw the boundary. A strict inequality uses a dashed boundary. A non-strict inequality uses a solid boundary.

## Test points

Choose a point not on the boundary and substitute it into the inequality. A true result means the region contains that point. The other side of the boundary is the complement.

## Solid and dashed boundaries

The boundary itself belongs to the solution only when equality is allowed. A circle and a parabola can create several regions. Test each region separately.
