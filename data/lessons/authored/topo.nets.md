# Nets and convergence

A net is a generalised sequence indexed by a directed set. It converges when it is eventually inside every neighbourhood of a point.

## Directed sets

A directed set is a partially ordered set in which every two elements have an upper bound. The finite subsets of a finite set ordered by inclusion form a directed set. A net assigns a value to every element of the directed set.

## Convergence

A net converges to a point when every neighbourhood of the point contains all values beyond some index. An eventually constant net converges to its eventual value. A net that alternates between two values has two cluster points.

## Cluster points

A cluster point is a point that every neighbourhood meets arbitrarily far out in the net. Even and odd subsequences can converge to different cluster points. The set of cluster points describes the possible limits of subnets.
