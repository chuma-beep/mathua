# Bounded linear operators

A bounded linear operator maps bounded sets to bounded sets. Its operator norm is the smallest constant that bounds the ratio of output to input.

## Operator norm

For a diagonal operator, the operator norm is the largest absolute diagonal entry. The operator stretches each coordinate independently. The maximum stretch is the norm.

## Boundedness test

Every finite matrix defines a bounded operator. The finite-dimensional unit ball is compact. A linear map on a finite-dimensional space is automatically bounded.

## Matrix example

Apply the operator to a vector by multiplying each component by its diagonal entry. The output components are the stretched inputs. The first component is the product of the first diagonal entry and the first input.
