# Telescoping sums

A telescoping sum cancels almost every term because each term is written as a difference of consecutive values. Only the first and last pieces survive.

## Partial fractions

A rational term can often be split into a difference, which is the usual way to create a telescoping sum.

## Cancellation

Write the first few and last few terms to see which survive. Usually the sum reduces to one endpoint minus the other.

## Infinite case

For an infinite telescoping sum the value is the limit of the partial sums, which exists exactly when the surviving endpoint converges.

To check your understanding, split the term, list early terms and take partial sums.

The cancellation is structural, so write the endpoints rather than adding terms.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
