# Sign charts for functions

A sign chart records where a function is positive, negative or zero. It turns an inequality into a sequence of test intervals separated by zeros and undefined points.

## Critical inputs

Zeros make the function equal to zero and undefined points break the chart. Together they are the only places the sign can change.

## Test values

Choose one input inside each interval and evaluate the sign there. The sign is constant on the whole interval.

## Reading the chart

A plus interval satisfies a greater-than inequality and a minus interval satisfies a less-than inequality. Endpoints are included only when the inequality is not strict.

To check your understanding, find zeros, pick one input per interval and choose plus or minus.

The chart answers an inequality without graphing the function.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
