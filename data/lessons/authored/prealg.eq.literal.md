# Solving a formula for a variable

## Rearranging by inverse operations

A literal equation contains several letters. Solving for one letter means isolating it while the other letters stay in the formula. Start with P = 2l + 2w. To solve for w, subtract 2l from both sides and then divide by 2. The result is w = (P - 2l) / 2. Undo addition before multiplication, just as you would when solving a numerical equation.

## Substituting known values

After rearranging, substitute the given values and compute. If P = 34 and l = 8, then w = (34 - 16) / 2 = 9. Keep the units consistent. For a volume formula V = lwh, solving for h gives h = V / (lw), so divide by the product of the other two dimensions. Choose the rearrangement that matches the variable the question asks for.

## Checking the rearranged formula

Substitute the recovered value into the original formula and see whether the stated value returns. For a trapezoid area A = (b1 + b2)h / 2, the rearranged height is h = 2A / (b1 + b2). Put the height back into the area formula. If the area matches, the rearrangement is correct. A check with numbers catches a sign error or a reversed division.
