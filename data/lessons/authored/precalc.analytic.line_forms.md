# Forms of a line

A line can be written in slope-intercept, point-slope or standard form. Each form displays different information and converts to the others by rearrangement.

## Slope-intercept

The form y = mx + b displays the slope and the y-intercept directly, which suits graphing.

## Point-slope

The form through a known point displays the slope and one point, which suits construction from data.

## Standard form

The form with both variables on one side suits systems and intercept finding, and its coefficients can be scaled without changing the line.

To check your understanding, read the slope, use a known point and collect the variables.

The same line has infinitely many equations, so a form is a presentation rather than a fact.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
