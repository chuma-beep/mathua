# The Fubini-Tonelli theorem

The Fubini-Tonelli theorem turns a double integral into an iterated integral. Tonelli's version applies to nonnegative functions, and Fubini's version adds integrability.

## Iterated integrals

For a constant function on a rectangle, the double integral is the value times the area. Integrating in either order gives the same number. The two orders are two ways to sum the same mass.

## Swapping the order

When the hypotheses hold, the order of integration can be exchanged. The value is unchanged. The theorem is the justification for changing the order in a computation.

## Finite grid check

On a finite grid, a double sum is a finite iterated sum. The two orders always agree. This is the discrete model of Fubini's theorem.
