# Adding three fractions in a different order

Addition is associative and commutative, so three fractions may be grouped in any order. A deliberate regrouping often creates a pair that sums to 1, which shortens the work.

## The method

Reorder the addends so that complementary fractions sit together. A pair such as \(\frac{1}{3}\) and \(\frac{2}{3}\) sums to 1 and a pair with the same denominator is easy to combine. The total does not depend on the grouping, so the choice is free. Choosing the pair is the only decision and any legal grouping returns the same value.

## A worked sum

Add \(\frac{1}{3}\), \(\frac{2}{5}\) and \(\frac{2}{3}\). Group the thirds first: \(\frac{1}{3} + \frac{2}{3} = 1\). Then add the remaining fifth to obtain \(1 + \frac{2}{5} = 1\frac{2}{5}\). A second case is \(\frac{3}{7} + \frac{1}{4} + \frac{4}{7}\), where the sevenths sum to 1 and the total is \(1\frac{1}{4}\).

## Checking the result

Use the least common denominator, which is 15 for the first case. The addends become \(\frac{5}{15}\), \(\frac{6}{15}\) and \(\frac{10}{15}\), with numerator sum 21. So the total is \(\frac{21}{15} = \frac{7}{5} = 1\frac{2}{5}\), matching the grouped answer. The second case gives \(\frac{12}{28} + \frac{7}{28} + \frac{16}{28} = \frac{35}{28} = \frac{5}{4} = 1\frac{1}{4}\).

Regrouping is legal because the sum ignores the order in which the parts are counted.
