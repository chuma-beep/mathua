# Decimals on a number line

## Reading Tenths on a Number Line

A decimal on the number line marks a position, not a size. Between 0 and 1 the segment is cut into ten equal parts. Each part is one tenth, written 0.1. The number 0.4 sits four parts to the right of 0, so it is a little less than halfway to 1.

Hundredths need a finer division. The number 0.45 lies halfway between 0.4 and 0.5, because it is four tenths and five hundredths. Reading a label means counting small steps from the nearest whole number, then naming the position those steps reach.

## Locating a Decimal Between Two Integers

Every decimal lies between two consecutive integers. To place 3.7, start at 3 and move seven tenths to the right. The point passes 3.1 and 3.2 and keeps going until it stops short of 4.

The integer part names the interval. The digits after the point name the position inside it. A value of 3.0 is the integer 3 itself, so it lands exactly on a tick mark rather than between two of them.

## Distance Between Decimal Points

Distance on the line is the difference of two positions. From 1.9 to 4.6 the distance is 2.7, found by subtracting 1.9 from 4.6. Counting steps agrees: 0.1 reaches 2.0, then 2.6 more reaches 4.6.

Direction matters when you travel left, but a distance itself is never negative. Subtract the smaller position from the larger one and attach the unit named on the axis.
