# Integrals of absolute values

An absolute value removes a sign, so integrate it by splitting at the point where the expression inside is zero.

## Where the sign changes

The expression inside the absolute value changes sign at its zero. Split the integral there.

On the negative side, \(|x|=-x\). On the positive side, \(|x|=x\).

The split point is not optional, because the formula changes there.

## Symmetry

For an even integrand, the integral over \([-a,a]\) is twice the integral over \([0,a]\) or \([-a,0]\) if the function is even.

\(|x|\) is even, so \(\int_{-a}^{a}|x|dx=a^2\).

Symmetry can save work, but only when the integrand is genuinely even.

## Checking the area

The integral of \(|x|\) is an area, so it cannot be negative. A negative answer signals a sign error in the piece.

Sketching the V-shape makes the two triangles visible and checks the arithmetic.

The same splitting idea handles \(|x-c|\) after a shift.

A shifted absolute value \(|x-c|\) splits at \(c\). Shifting does not change the area of the corresponding triangles.
