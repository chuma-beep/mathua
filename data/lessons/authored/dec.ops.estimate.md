# Estimating with decimals

## Rounding decimals

Round each decimal to a convenient whole number before estimating. Look at the digit to the right of the rounding place. A digit of 5 or more rounds up, and a digit below 5 rounds down.

State the rounded values in the explanation so the estimate can be checked. Rounding both numbers in the same direction can make the estimate noticeably high or low.

## Estimating sums and products

For a sum, add the rounded values. For a product, multiply the rounded values. The estimate is not the exact answer, so do not present it as one.

Use the estimate to judge whether an exact answer is reasonable. An exact answer that is far from the estimate usually contains a place-value or operation error.

## Comparing with the exact value

Compute the exact value after estimating and compare the two results. The difference shows how much the rounding changed the answer. A small difference is expected when the decimals are close to whole numbers.

The comparison is a check on the arithmetic, not a reason to replace the exact answer with the estimate. Keep the exact value when the question asks for it.
