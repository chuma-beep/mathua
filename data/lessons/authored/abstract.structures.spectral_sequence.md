# Spectral sequences

A spectral sequence is a bookkeeping device that converges to a graded object through successive pages of differentials.

## Pages

Each page has a differential whose square is zero, and the next page is the homology of the previous one.

## Bidegree

On an \(r\) by \(r\) grid the \(E_2\) page has \(r^2\) entries.

## Convergence

The sequence converges when the differentials eventually vanish on each entry.

To check your understanding, take homology, draw the grid and track an entry.

Spectral sequences compute a limit from a grid of approximations.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller numbers and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
