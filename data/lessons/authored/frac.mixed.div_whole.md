# Dividing a mixed number by a whole number

A mixed number divided by a whole number is a sharing problem. Convert the mixed number to an improper fraction, divide by the whole number and return to mixed form when the answer is larger than 1.

## The method

Write \(w\frac{a}{b}\) as \(\frac{wb + a}{b}\), then divide by the whole number \(n\) by multiplying the denominator: the quotient is \(\frac{wb + a}{bn}\). The divisor \(n\) is positive, so it is never zero. Reduce the result and convert back if needed. With \(2\frac{1}{2}\) and 5 the quotient is \(\frac{1}{2}\). A quotient below 1 is a share of one whole, while a quotient above 1 names several wholes.

## A worked example

Compute \(2\frac{1}{2} \div 5\). The mixed number is \(\frac{5}{2}\), so the quotient is \(\frac{5}{2} \times \frac{1}{5} = \frac{5}{10} = \frac{1}{2}\). Each of five shares receives one half. A case that stays above 1 is \(3\frac{3}{4} \div 3 = \frac{15}{4} \times \frac{1}{3} = \frac{15}{12} = \frac{5}{4}\), which is \(1\frac{1}{4}\).

## Checking the result

Multiply the quotient by the whole number: \(5 \times \frac{1}{2} = \frac{5}{2}\), which is \(2\frac{1}{2}\). For the second case, \(3 \times \frac{5}{4} = \frac{15}{4}\), which is \(3\frac{3}{4}\). Both checks restore the mixed number, so the conversion and the division were correct.

Dividing by a whole number divides the value into that many equal shares.
