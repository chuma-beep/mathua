# Finding a missing subtrahend

The subtrahend is the number taken away in a subtraction. When it is unknown, it is the minuend minus the difference.

## The method

From \(\frac{a}{b} - x = \frac{c}{d}\), add \(x\) and subtract \(\frac{c}{d}\) to obtain \(x = \frac{a}{b} - \frac{c}{d}\). Write both fractions over a common denominator, subtract the numerators and reduce. The result cannot exceed the minuend when the difference is nonnegative. The subtraction and the addition are inverse operations, so the recovered value is exact. For \(\frac{3}{4} - x = \frac{1}{4}\) the subtrahend is \(\frac{1}{2}\).

## A worked difference

Solve \(\frac{7}{9} - x = \frac{2}{9}\). Subtracting the difference gives \(x = \frac{7}{9} - \frac{2}{9} = \frac{5}{9}\). A case with unlike denominators is \(\frac{5}{6} - x = \frac{1}{3}\). The difference becomes \(\frac{2}{6}\), so \(x = \frac{5}{6} - \frac{2}{6} = \frac{3}{6} = \frac{1}{2}\). The unknown is a half, which is smaller than five sixths and larger than the difference.

## Checking the result

Subtract the found value from the minuend: \(\frac{5}{6} - \frac{1}{2} = \frac{5}{6} - \frac{3}{6} = \frac{2}{6} = \frac{1}{3}\), which is the stated difference. The first case checks as \(\frac{7}{9} - \frac{5}{9} = \frac{2}{9}\). A decimal check gives \(0.8333 - 0.5 = 0.3333\), matching one third.

The unknown subtrahend is the part of the minuend that the difference does not account for.
