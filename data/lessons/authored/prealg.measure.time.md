# Converting units of time

## Hours and minutes

One hour contains 60 minutes. Multiply the number of hours by 60 and add any extra minutes. Two hours and 15 minutes is 135 minutes.

Keep the units in the calculation. Multiplying hours by 60 changes the unit from hours to minutes, so the result is a number of minutes.

## Minutes and seconds

One minute contains 60 seconds. Multiply the number of minutes by 60 to convert to seconds. A time given in hours and minutes can first be converted to minutes and then to seconds.

When a time has several units, convert from the largest unit to the smallest one step at a time. This keeps each multiplication easy to check.

## Elapsed time

Elapsed time is the difference between an end time and a start time. Convert both times to the same unit before subtracting. If the end time is after midnight, add 24 hours to the end time before subtracting.

Check the elapsed time by adding it back to the start time. The result must equal the end time.

A final check is to restate the answer in the units and context of the original question. If the result is plausible and the units match, the calculation is ready.
