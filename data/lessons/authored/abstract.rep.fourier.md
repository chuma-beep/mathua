# Fourier analysis on finite groups

Fourier analysis on a finite group expands functions in matrix coefficients of irreducible representations. For abelian groups it reduces to characters.

## Expansion

A function on a finite group is a linear combination of matrix coefficients of its irreducibles.

## Abelian case

An abelian group of order n has n characters, and the Fourier transform is an isomorphism of the function space.

## Inversion

The inverse transform averages the coefficients over the group.

To check your understanding, choose coefficients, count characters and average the coefficients.

Representation theory is Fourier analysis without commutativity.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller numbers and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
