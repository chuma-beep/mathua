# Estimating a quotient of fractions

An estimate for a quotient rounds the dividend and the divisor before dividing. Because division by a fraction below 1 enlarges the dividend, the estimate is often larger than the dividend itself.

## The method

Round each fraction to 0, \(\frac{1}{2}\) or 1, then divide the rounded values. A divisor rounded down makes the estimate too large and a divisor rounded up makes it too small. Rounding the dividend moves the estimate in the same direction as the rounding.

## A worked quotient

Estimate \(\frac{7}{8} \div \frac{1}{4}\). The dividend rounds to 1 and the divisor is exactly \(\frac{1}{4}\), so the estimate is 4. The exact quotient is \(\frac{7}{8} \times 4 = \frac{7}{2}\), which is 3.5. The estimate is high by one half, because the dividend was rounded up from 0.875 to 1. A second case is \(\frac{8}{9} \div \frac{2}{3}\), estimated as \(1 \div \frac{2}{3} = 1.5\), with an exact value of \(\frac{4}{3}\).

## Checking the result

Bracket the first quotient. The lower bound uses \(\frac{3}{4} \div \frac{1}{2} = 1.5\) and the upper bound uses \(1 \div \frac{1}{4} = 4\). The exact value 3.5 lies between them, so the estimate is credible. A bracket that excludes the exact value signals a rounding error.

An estimate of a quotient is only useful when its bracket contains the answer.
