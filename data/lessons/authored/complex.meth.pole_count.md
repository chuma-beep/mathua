# Counting poles

The number of poles inside a contour is read from the denominator's factors.

## Inside

Factor the denominator and count the roots that lie inside the contour, with multiplicity.

## Outside

Roots outside the contour do not contribute to the contour integral and are excluded from the count.

## Multiplicity

A repeated factor counts once per repetition, so the pole count is the degree inside the contour.

To check your understanding, factor the denominator, test the exterior and count repetitions.

Pole counting is root counting for the denominator.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller values and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
