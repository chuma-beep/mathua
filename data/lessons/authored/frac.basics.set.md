# A fraction of a set

A fraction can describe part of a collection, not only part of one whole. The denominator names the number of equal groups and the numerator names how many groups are selected.

## Equal groups

Divide the set into as many equal groups as the denominator. The number per group is the total divided by the denominator. This step requires the total to be divisible by the denominator.

## The selected groups

Multiply the number per group by the numerator. The result is the number of objects in the selected part. The remainder is the total minus that selected count.

## The remainder

The unselected objects form the rest of the set. Their count is the total minus the selected count. The selected and remaining counts add back to the whole set.

The three sections form one chain. The first names the object, the second performs the computation and the third reads the result in context.
