# Dividing by a unit fraction

Dividing by \(\frac{1}{n}\) asks how many parts of size \(\frac{1}{n}\) fit into the dividend. The answer is the dividend multiplied by \(n\), so the operation enlarges any positive value.

## The method

For a fraction \(\frac{a}{b}\) and a positive whole number \(n\), \(\frac{a}{b} \div \frac{1}{n} = \frac{a}{b} \times n = \frac{an}{b}\). Multiply the numerator by \(n\), then reduce. The divisor is never zero, because a unit fraction always has numerator 1.

## A worked quotient

Compute \(\frac{3}{4} \div \frac{1}{8}\). Multiplying by 8 gives \(\frac{24}{4} = 6\). The quotient means that six eighths fit exactly into three quarters, which is visible on a number line marked in eighths. The count is a whole number because the dividend is an exact multiple of the unit fraction. A second case is \(\frac{2}{3} \div \frac{1}{6} = \frac{12}{3} = 4\), so four sixths fill two thirds.

## Checking the result

Multiply the quotient by the divisor: \(6 \times \frac{1}{8} = \frac{6}{8} = \frac{3}{4}\), which is the dividend. For the second case, \(4 \times \frac{1}{6} = \frac{4}{6} = \frac{2}{3}\). The check restores the dividend, so the count of parts is correct.

Division by a unit fraction counts parts and the count is larger than the dividend.
