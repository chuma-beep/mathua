# The domain of a function

The domain of a function is the set of inputs for which its rule produces a real output. Two restrictions do most of the work: division by zero and even roots of negative numbers.

## Denominators

A denominator may not vanish. Solving the denominator equal to zero removes those inputs from the domain.

## Even roots

An even root needs a non-negative radicand. The inequality that makes the radicand non-negative gives the domain.

## Logarithms

A logarithm needs a positive argument, so its domain is the solution set of the argument being positive.

To check your understanding, find excluded inputs, set the radicand non-negative and require a positive argument.

Intersect every restriction, because an input must satisfy all of them at once.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
