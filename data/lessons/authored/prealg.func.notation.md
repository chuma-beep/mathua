# Function notation

## Reading f of x

Function notation names a rule with a letter and shows the input in brackets. In \\(f(x) = 3x + 1\\) the letter f is the name of the rule. The x inside the brackets is the input. The expression is not f multiplied by x.

The output is written the same way. The statement \\(f(4) = 13\\) says that the rule turns an input of 4 into an output of 13. Read it as "f of 4 equals 13" and the notation stops looking like multiplication.

## Evaluating Function Notation

Evaluating means replacing the input everywhere it appears. Using \\(f(x) = 3x + 1\\), the value at an input of -2 is \\(f(-2) = 3(-2) + 1\\), which simplifies to \\(-6 + 1 = -5\\).

The brackets around the input carry the sign, so a negative input stays negative through the multiplication. A second input, say 10, gives \\(f(10) = 31\\). The two results differ because the rule is a relationship, not a constant.

## Solving f of x for an Input

Sometimes the output is known and the input is wanted. If \\(f(x) = 16\\), then \\(3x + 1 = 16\\), so \\(3x = 15\\) and \\(x = 5\\).

The answer is an input, not an output, so it needs no f written around it. Check it by evaluating: \\(f(5) = 16\\), which matches the given value and confirms the direction of the work.
