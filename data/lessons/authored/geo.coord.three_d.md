# Three-dimensional coordinates

A point in space needs three coordinates. Distance extends the plane formula by adding the squared z difference.

## Coordinates

A spatial point is an ordered triple, and each coordinate measures displacement along one axis.

## Distance

The distance between two points squares the difference in each coordinate, adds the three squares and takes the square root.

## Midpoints

The midpoint averages each coordinate separately, exactly as in the plane.

To check your understanding, read three coordinates, subtract coordinates and average x.

One extra coordinate adds one squared term to every distance.

Each section above supplies the reasoning for one practice family, so work a numeric instance of each before moving on. Write the first step of every instance down before you compute the final value, because the grader checks the number but the method is what the next concept assumes. If an instance refuses to settle, redraw it with smaller coefficients and check the sign of every term; the arithmetic in these families is exact, so a mismatch means a sign or an order of operations, not an approximation.
