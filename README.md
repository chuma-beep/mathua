# Mathua — Math Understanding Agent

An open-source adaptive math learning system built with Go.

## Features

- Adaptive learning with SM-2 spaced repetition
- Concept DAG for prerequisite tracking
- Problem generation for multiple domains
- Symbolic grading with SymPy integration
- TUI, Web, and Desktop interfaces

## Quick Start

```bash
go run ./cmd/mathua
```

## Development

```bash
make run      # Run the application
make build   # Build the binary
make test    # Run tests
make serve   # Start web server
```
